## Problem Analysis

**錯誤重現**：
```
$ python3 .claude/hooks/hook-completeness-check.py
ModuleNotFoundError: No module named 'yaml'
```

**Import chain 追蹤**：
1. `hook-completeness-check.py:32` → `from project_init.lib.hook_checker import ...`
2. `project_init/lib/__init__.py:48` → `from .onboard_checker import ...`
3. `project_init/lib/onboard_checker.py:10` → `import yaml`
4. 系統 Python 無 PyYAML → `ModuleNotFoundError`

**根因**：`hook-completeness-check.py` 使用 `#!/usr/bin/env python3`（系統 Python），但 `project_init/__init__.py` 在某次修改後新增了 `onboard_checker` 的 import，而 `onboard_checker` 依賴 PyYAML。其他 hook 使用 `#!/usr/bin/env -S uv run --quiet --script` 搭配 PEP 723 宣告依賴，不受影響。

**影響**：自 2026-03-13 起，每次 SessionStart 都會觸發 health monitor 的 [FAIL] 報告（103h > CRITICAL_THRESHOLD_HOURS=48h），stderr 輸出被 Claude Code 顯示為 `hook error`。

**修復方向**：
- 方案 A（推薦）：將 shebang 改為 `uv run --script` + PEP 723 header（與其他 hook 一致）
- 方案 B：修正 `__init__.py` lazy import（影響範圍較大，需驗證其他模組）
