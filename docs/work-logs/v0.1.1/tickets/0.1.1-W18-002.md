## Problem Analysis

**搜尋指令**：已在原始碼中確認共用模式

**確認的位置**：
1. `.claude/skills/project-init/project_init/lib/package_manager.py:180` - `_find_uv_tool_site_packages()`
   - 在 `site_packages` 遞歸搜尋 `package_module` 子目錄
   - 使用 `for site_packages in uv_tools_dir.rglob("site-packages")`

2. `.claude/skills/project-init/project_init/lib/package_manager.py:245` - `resolve_source_module_dir()`
   - 在 `source_dir` 搜尋 `installed_dir.name` 子目錄
   - 使用 `source_dir / installed_dir.name` 判斷存在性

**共用概念**：兩處都進行「在父目錄下搜尋特定名稱的模組子目錄」的邏輯，可提取為 `_locate_module_subdir()` 私有函式。

## Solution

### 共用函式提取

在 `.claude/skills/project-init/project_init/lib/package_manager.py` 中提取共用函式：

```python
def _locate_module_subdir(parent_dir: Path, module_name: str) -> Optional[Path]:
    """在父目錄下搜尋特定名稱的模組子目錄.

    用於定位已安裝模組或 source 目錄下的特定子目錄。
    若 parent_dir 下存在直接或深層嵌套的同名目錄，回傳第一個找到的。
    """
```

### 重複模式分析

1. **_find_uv_tool_site_packages** (原第 195-198 行)：
   - 在 site-packages 目錄下搜尋 package_module 子目錄
   - 模式：`for site_packages in parent.rglob(...): candidate = parent / module_name`

2. **resolve_source_module_dir** (原第 261-263 行)：
   - 在 source 目錄下搜尋 installed_dir.name 子目錄
   - 模式：`candidate = source_dir / installed_dir.name`

### 重構結果

- 提取 `_locate_module_subdir` 私有函式（package_manager.py 內部）
- `_find_uv_tool_site_packages` 改用共用函式（第 219 行）
- `resolve_source_module_dir` 改用共用函式（第 284 行）
- 函式長度控制：共用函式 8 行，均符合品質要求
