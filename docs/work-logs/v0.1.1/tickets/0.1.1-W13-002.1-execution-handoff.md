### M11 [中優先級] get_worktree_ahead_behind 可用 rev-list --left-right 合併

**文件**: `.claude/skills/worktree/scripts/worktree_manager.py` 行 182-213

**問題**: 函式執行兩次 `git rev-list --count` 來計算 ahead 和 behind。可用 `--left-right` 和單次呼叫優化。

**修復要求**:
- 合併為單次 git 呼叫，使用 `--left-right` 參數

**修復方式**:
```python
def get_worktree_ahead_behind(branch: str, base: str = DEFAULT_BASE_BRANCH) -> tuple[int, int]:
    """計算分支相對於 base 的 ahead/behind commit 數"""
    try:
        # M11 修復：合併兩次 rev-list 為單次呼叫
        # 原因：避免重複執行 git 命令，提升效能
        success, output = run_git_command(
            ["rev-list", "--left-right", "--count", f"{base}...{branch}"]
        )
        if not success:
            return (0, 0)

        # 輸出格式："{ahead_count}\t{behind_count}"
        parts = output.split('\t')
        if len(parts) == 2:
            ahead = int(parts[0])
            behind = int(parts[1])
            return (ahead, behind)
        return (0, 0)
    except Exception as e:
        print(f"[Warning] Failed to calculate ahead/behind for {branch}: {e}", file=sys.stderr)
        return (0, 0)
```
