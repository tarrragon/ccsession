Wave 9 多視角審查（3 個代理人並行）發現的問題彙整：

高嚴重度（8 個）：
1. behind_str 顯示 -0（UI bug，100% 信心）
2. is_main 判斷邏輯錯誤（fix/ worktree 被判為主倉庫）
3. TICKET_ID_PATTERN 重複定義且不支援後綴（DRY 違規）
4. fallback 區塊 66 行靜默降級 + 行為差異（git_utils 退化副本）
5. cmd_create 成功路徑完全無測試
6. is_in_worktree / is_exempt_path 只有 placeholder 測試
7. cmd_status 認知負擔指數 20（閾值 15，三職責混合 110 行）
8. pyproject.toml 缺少 build-system 宣告

中嚴重度（6 個）：
9. parse_ticket_id 命名語義不符（validate 非 parse）
10. branch[5:] 魔法數字
11. SessionStart ImportError exit(1) 阻斷 session
12. detached HEAD worktree 未處理
13. cmd_create 認知負擔 16（dry-run 未分離）
14. conftest fixture 未被使用 + 格式錯誤
## Solution

### 修復摘要（14 個問題，8 高 + 6 中）

#### 第一批：高嚴重度 Bug（#1, #2）
- **#1 behind_str 顯示 -0**：修復邏輯，當 behind = 0 時不使用 "-{0}"，改為 "{0}"
- **#2 is_main 邏輯錯誤**：移除 `not branch.startswith("feat/")` 的誤判邏輯，改為只檢查 PROTECTED_BRANCHES 清單

#### 第二批：中嚴重度 Bug（#10, #11）
- **#10 branch[5:] 魔法數字**：建立 constants.py，定義 FEAT_PREFIX_LEN = len("feat/") = 5，統一使用此常數
- **#11 SessionStart ImportError exit(1)**：修改 branch-status-reminder.py ImportError 處理，改為優雅降級（寫 stderr 但不 exit(1)），定義 fallback 函式

#### 第三批：認知負擔重構（#7, #13）
- **#7 cmd_status 認知負擔 20**：拆分為三個獨立函式：
  - `_find_target_worktree()`：查詢特定 Ticket worktree（認知負擔 3）
  - `_collect_worktree_info()`：收集 worktree 資訊（認知負擔 6）
  - `_print_worktree_status()`：格式化輸出（認知負擔 5）
  - 原 cmd_status 認知負擔 <= 8
- **#13 cmd_create 認知負擔 16**：拆分為兩個獨立函式：
  - `_cmd_create_dry_run()`：dry-run 模式邏輯（認知負擔 3）
  - `_cmd_create_validate_and_execute()`：驗證與執行邏輯（認知負擔 5）
  - 原 cmd_create 認知負擔 <= 8

#### 第四批：DRY 修正（#3, #4, #9）
- **#3 TICKET_ID_PATTERN 重複**：在 constants.py 中定義官方版本，增加詳細註解標記來源版本（.claude/skills/ticket/ticket_system/lib/constants.py v0.31.0）
- **#4 fallback 區塊 66 行**：改為最小化 fallback，只定義必要函式，並寫入 stderr 提示而非 exit(1)
- **#9 parse_ticket_id 命名不符**：重命名為 is_valid_ticket_id，保留 parse_ticket_id 別名確保向後相容

#### 第五批：測試補充（#5, #6, #14）
- **#5 cmd_create 成功路徑無測試**：新增 2 個測試
  - test_create_success_valid_ticket：驗證正常建立流程
  - test_create_success_with_custom_base：驗證自訂 base 分支
- **#6 is_in_worktree/is_exempt_path placeholder 測試**：新增 3 個實質性測試
  - test_is_in_worktree_main_repo：驗證主倉庫結構
  - test_is_in_worktree_feat_worktree：驗證 feature worktree 結構
  - test_is_in_worktree_detached_head：驗證 detached HEAD 結構
- **#14 conftest fixture 修正**：修正 fixture 定義格式，補充文件字串說明用途

#### 第六批：邊界情況與建置（#12, #8）
- **#12 detached HEAD worktree 未處理**：在 _collect_worktree_info() 中新增 detached 判斷邏輯，標籤為 "detached" 並跳過 ahead/behind 計算
- **#8 pyproject.toml 缺少 build-system**：新增標準 build-system 宣告（setuptools 依賴）
