## 實作完成

### 核心函式實作

**1. scan_all_tickets() -> List[TicketVersionInfo]**
   掃描 docs/work-logs/v*/tickets/*.md 全部 453 個 Ticket 檔案
   對每個 Ticket 收集三個版本來源：
   - id_version: 從 Ticket ID（如 "0.1.0-W15-001"）提取
   - frontmatter_version: 從 YAML frontmatter 的 version 欄位讀取
   - directory_version: 從目錄路徑（如 "v0.1.0/tickets/"）提取

**2. detect_mismatches(tickets: List[TicketVersionInfo]) -> List[VersionMismatch]**
   比對每個 Ticket 的三個版本值，偵測三種不一致類型：
   - id_vs_directory: Ticket ID 版本與目錄版本不同
   - frontmatter_vs_directory: Frontmatter 版本與目錄版本不同
   - id_vs_frontmatter: Ticket ID 版本與 frontmatter 版本不同
   以目錄版本作為 source of truth

### 資料結構

**TicketVersionInfo** - 儲存 Ticket 版本資訊
   - file_path: 檔案完整路徑
   - ticket_id: 核心 Ticket ID
   - id_version: 從 ID 提取的版本號
   - frontmatter_version: Frontmatter 中的版本
   - directory_version: 目錄版本（source of truth）
   - 已凍結：資料類別不可變

**VersionMismatch** - 儲存發現的版本不一致
   - ticket_info: 原始 TicketVersionInfo
   - mismatch_type: 不一致類型
   - expected_version: 目錄版本（期望值）
   - actual_version: 不一致的版本值
