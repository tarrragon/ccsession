## Problem Analysis

### 來源

IMP-035 錯誤模式：`.claude/error-patterns/implementation/IMP-035-guard-clause-filter-state-conflict.md`

### 核心問題

函式同時承擔「全量列表」和「篩選查詢」兩種模式時，guard clause（如 `if not results: return "無資料"`）只考慮全量場景。篩選後的合法單一結果被 guard clause 誤判為「無資料」。

### 防護目標

1. 在 error-patterns 文件中補充具體防護措施和檢查清單
2. 在 quality-common.md 加入多模式函式 guard clause 設計規則（類似 1.2.3 破壞性操作防護）
3. 確保 Phase 4 重構評估時能引用此防護規則
