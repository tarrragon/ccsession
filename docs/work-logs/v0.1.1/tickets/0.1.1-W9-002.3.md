#### 1. git_utils.py — is_in_worktree() 函式

在 `git_utils.py` 新增 `is_in_worktree()` 函式（行號 207-248）：

```python
def is_in_worktree() -> bool:
    """
    檢查當前工作目錄是否在 git worktree（非主倉庫）中

    實作邏輯：
    - 執行 git rev-parse --git-common-dir 取得主 .git 目錄
    - 執行 git rev-parse --git-dir 取得當前 .git 目錄
    - 正規化兩個路徑使用 os.path.abspath()
    - 若兩者相同 → 在主倉庫中，返回 False
    - 若兩者不同 → 在 worktree 中，返回 True

    異常時保守預設返回 False
    """
```

**驗證結果**：
- ✅ 語法檢查：py_compile 通過
- ✅ 函式呼叫測試：成功執行
- ✅ 邏輯測試：當前在主倉庫中返回 False（符合預期）
