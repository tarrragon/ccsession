## Solution

### 實作完成

已在 `.claude/skills/ticket/ticket_system/lib/audit_version.py` 建立完整模組，包含：

#### 1. TicketVersionInfo dataclass
- **職責**：記錄單個 Ticket 檔案的版本資訊
- **屬性**：
  - `file_path`: 檔案完整路徑
  - `ticket_id`: 原始 ID（可能帶後綴）
  - `id_version`: 從 ID 提取的版本號
  - `frontmatter_version`: frontmatter 中的 version 欄位
  - `directory_version`: 目錄中的版本號
- **用途**：scan_all_tickets() 的標準輸出格式

#### 2. DuplicateTicket dataclass
- **職責**：記錄重複偵測的結果
- **屬性**：
  - `ticket_id`: 核心 Ticket ID（已去後綴）
  - `locations`: List[TicketVersionInfo] 所有重複位置
  - `recommended_version`: 根據 ID 版本號推薦的正確版本
- **特性**：ID 版本號作為 source of truth 判斷推薦位置

#### 3. detect_duplicates() 函式
- **簽名**：`detect_duplicates(tickets: List[TicketVersionInfo]) -> List[DuplicateTicket]`
- **算法**：
  1. 按核心 ID（去後綴）分組，使用 `defaultdict(list)`
  2. 篩選出現在 2+ 個不同 directory_version 的分組
  3. 推薦版本取自 ticket_group[0].id_version（所有同組 ID 版本相同）
- **邊界處理**：防守式編程，無效 ID 格式直接跳過（不報錯）
- **文件**：完整 docstring 含使用範例

#### 4. 程式碼品質
- 完整型別標註
- PEP 8 風格符合
- 無魔法數字（使用具名常數或邏輯清晰）
