### 虛擬碼層次
- **主函式流程**：路徑轉換 → 前置驗證三層 → 單一原子命令 → 成功/失敗回傳
- **資料流程圖**：輸入驗證 → 三層防禦檢查 → 原子命令執行 → 輸出結果
- **控制流程圖**：參數解析 → dry-run 分支 → 函式呼叫 → 結果輸出 → 程序退出

### 三個主要改寫點
1. **第 96 行**：移除 `git checkout -b {branch} {base_branch}` 及其錯誤檢查
   - 改為：`git worktree add -b {branch} {worktree_abs_path} {base_branch}`（原子命令）

2. **第 103-104 行**：移除手動回滾邏輯 `run_git_command(["branch", "-D", branch])`
   - 原因：原子操作失敗時 git 自動清理，無需手動刪除

3. **第 140 行 dry-run 輸出**：改為顯示單一 git 命令
   ```
   git worktree add -b {branch} {abs_path} {base}
   ```
