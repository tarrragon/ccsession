## Solution

### Hook 設計摘要

#### 檔案位置
- **Hook 檔名**: `worklog-path-guard-hook.py`
- **路徑**: `.claude/hooks/worklog-path-guard-hook.py`
- **Hook 類型**: PostToolUse（Write 工具）

#### 功能
- **觸發條件**: 當 Write 工具的目標路徑為 `docs/work-logs/*.md`（根目錄直接）時觸發
- **行為**: 輸出 WARNING 提醒（不阻止操作，exit code 0）
- **雙通道輸出**: 同時寫入 stderr（使用者可見）和日誌檔（持久化）

#### 排除邏輯
Hook 會自動排除以下路徑（不觸發警告）：
- `docs/work-logs/v{version}/*.md` （在版本子目錄下）
- `docs/work-logs/v{version}/tickets/*.md` （在 tickets 子目錄下）
- 非 .md 檔案（不防護）

#### 警告訊息智能化
Hook 根據檔案名推測應放的位置：
1. 版本號開頭 (v0.1.0-...) → 提示「應放在 docs/work-logs/v{version}/」
2. Ticket ID (0.1.0-W1-...) → 提示「應放在 docs/work-logs/v{version}/tickets/」
3. 其他 → 提示「應放在 v{version}/ 或 v{version}/tickets/」

#### 技術實作細節
- **PEP 723 格式**: uv single-file script，無外部依賴
- **hook_utils 整合**: 使用 `setup_hook_logging` 和 `run_hook_safely` 進行統一日誌管理
- **日誌路徑**: `.claude/hook-logs/worklog-path-guard/`
- **Python 版本**: >= 3.11（相容性）

#### Hook 註冊說明（待 PM 執行）
Hook 需要在 `.claude/settings.json` 中註冊到 PostToolUse Write hooks 中：

```json
{
  "matcher": "Write",
  "hooks": [
    // ... 現存 hooks ...
    {
      "type": "command",
      "command": "$CLAUDE_PROJECT_DIR/.claude/hooks/worklog-path-guard-hook.py"
    }
  ]
}
```

**註冊位置**: `.claude/settings.json` 的 `PostToolUse.Write.hooks[]` 陣列末尾
