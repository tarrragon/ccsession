### 實作概述

1. **新建命令模組** `audit_version.py`
   - 實作 `execute_audit_version()` 主函式
   - 支援 dry-run（預設）和 --fix 兩種模式
   - 支援 --version 參數篩選特定版本

2. **報告格式化** `_format_version_audit_report()`
   - 生成易讀的審計報告
   - 分別列示版本不一致和重複 Ticket
   - 提供修復建議（move/frontmatter update/delete）

3. **修復操作**
   - `_fix_mismatches()`: 修正 frontmatter 中的 version 欄位
   - `_fix_duplicates()`: 刪除非推薦版本的重複檔案
   - 前置操作確認，執行後回報結果

4. **CLI 整合**
   - 在 `command_tracking_messages.py` 新增 `AuditVersionMessages` 類別
   - 在 `track.py` 中：
     * 匯入 `execute_audit_version`
     * 在命令處理器字典註冊 "audit-version"
     * 新增 `_register_version_audit_commands()` 函式
     * 在 `_register_all_subcommands()` 中呼叫註冊函式

### 使用方式

```bash
# 預設 dry-run，顯示問題
ticket track audit-version

# 自動修復
ticket track audit-version --fix

# 只檢查特定版本
ticket track audit-version --version 0.1.0
ticket track audit-version --version 0.1.0 --fix
```
