## 設計核心邏輯

### 三層知識管理系統的分工

| 系統 | 存儲位置 | 特點 | 使用場景 |
|------|---------|------|---------|
| continuous-learning | memory / .claude/skills/learned/ | 個人、靈活、支援連結 | 個人發現、通用最佳實踐 |
| error-pattern | docs/error-patterns/categories/ | 團隊共享、系統性、可 Ticket 化 | 系統錯誤、防護缺陷 |
| tech-debt-capture | Phase 4 工作日誌 → Ticket | 架構改善、版本對應、自動化 | Phase 4 技術債務 |

### AskUserQuestion #16 選項邏輯

```
不記錄 (skip)
    ↓
記錄到 memory (/continuous-learning)
    ↓
記錄到 error-pattern (/error-pattern add)
    ↓
兩者都記錄 (memory + error-pattern)
```
