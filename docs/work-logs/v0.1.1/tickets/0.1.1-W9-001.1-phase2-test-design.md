## 一、測試設計概述

### 核心測試目標

基於 Phase 1 的 4 層優先順序策略，設計覆蓋以下場景的完整測試套件：

1. **環境變數優先路徑**（CLAUDE_PROJECT_DIR 設定）
2. **git rev-parse 優先路徑**（worktree 場景修復）
3. **CLAUDE.md 搜尋 fallback 路徑**（git 不可用）
4. **cwd fallback 路徑**（最終保障）
5. **向後相容性**（現有呼叫端無回歸）
6. **兩檔案對稱性**（hook_base.py 和 paths.py 行為一致）

### 測試分層策略

| 層級 | 測試類型 | 涵蓋內容 |
|------|---------|---------|
| Layer 1 | 單元測試 — 正常流程 | git rev-parse 成功、環境變數、CLAUDE.md 搜尋 |
| Layer 2 | 單元測試 — 邊界條件 | 搜尋深度邊界、無 CLAUDE.md、symlink |
| Layer 3 | 單元測試 — 異常處理 | git 命令不存在、timeout、非 git repo |
| Layer 4 | 整合測試 — 實作對稱 | hook_base.py vs paths.py 行為一致 |
| Layer 5 | 回歸測試 — 向後相容 | 現有呼叫端無需修改 |

### Mock 策略（Sociable Unit Tests）

| 依賴類型 | Mock 策略 | 理由 |
|---------|---------|------|
| subprocess.run（git 命令） | Mock | 外部命令，測試不關心實際執行 |
| os.environ（環境變數） | Mock (patch.dict) | 隔離環境，測試各優先級 |
| Path.cwd()（當前目錄） | Mock (patch) | 模擬不同 cwd 場景 |
| 檔案系統操作（CLAUDE.md 搜尋） | 真實（tmp_path fixture） | 測試實際搜尋邏輯 |
| pathlib.Path（路徑物件） | 不 Mock | 內層邏輯，直接使用真實物件 |

## 三、邊界條件測試清單

| 邊界條件 | 對應場景 | 測試方法 |
|---------|---------|---------|
| cwd = repo 根目錄 | 正常 git repo | 驗證回傳 repo 根目錄 |
| cwd = repo 子目錄深層（5+ 層） | 深層子目錄 | 驗證 git 正確回傳根目錄 |
| cwd = worktree（無 CLAUDE.md） | worktree 修復 | 驗證回傳源 repo 根目錄 |
| cwd = 非 git 目錄 | 非 git repo | 驗證 fallback 到 cwd |
| CLAUDE_MD_SEARCH_DEPTH = 5，超過 5 層 | 搜尋深度限制 | 驗證停止搜尋，進入 cwd fallback |
| symlink 目錄結構 | symlink 解析 | 驗證回傳實際路徑 |
| git 命令在特殊 PATH 上 | 環境因素 | mock subprocess 處理 |
| CLAUDE_PROJECT_DIR 設為絕對路徑 | 環境變數有效性 | 驗證直接回傳（不驗證路徑） |

## 四、Mock 物件設計

### 4.1 subprocess.run Mock

```python
# 成功路徑：git rev-parse --show-toplevel 回傳 "/git/root"
mock_subprocess = MagicMock()
mock_subprocess.return_value = CompletedProcess(
    args=["git", "rev-parse", "--show-toplevel"],
    returncode=0,
    stdout="/git/root\n"
)

# 失敗路徑：git 命令回傳非 0
mock_subprocess.return_value = CompletedProcess(
    args=["git", "rev-parse", "--show-toplevel"],
    returncode=128,
    stdout=""
)

# 例外路徑：FileNotFoundError（git 命令不存在）
mock_subprocess.side_effect = FileNotFoundError("git command not found")

# 例外路徑：TimeoutExpired（git 命令超時）
mock_subprocess.side_effect = subprocess.TimeoutExpired(
    cmd="git rev-parse --show-toplevel",
    timeout=5
)
```

### 4.2 Path.cwd() Mock

```python
# 模擬不同 cwd 環境
with patch("pathlib.Path.cwd") as mock_cwd:
    mock_cwd.return_value = Path("/custom/cwd")
    result = get_project_root()
```

### 4.3 環境變數 Mock

```python
# 模擬 CLAUDE_PROJECT_DIR 設定
with patch.dict("os.environ", {"CLAUDE_PROJECT_DIR": "/custom/project"}):
    result = get_project_root()

# 模擬環境變數未設定
with patch.dict("os.environ", {}, clear=True):
    result = get_project_root()
```
