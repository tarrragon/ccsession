#### 3.2 修改 `scan_custom_packages()` 函數（lines 61-97）

**修改策略**：
- 保留函數簽名和文件字符串
- 使用 `scan_skills_directory()` 掃描
- 將返回結果轉換為 `list[PackageInfo]` 格式

**虛擬碼**：
```python
def scan_custom_packages(project_root: Path) -> list[PackageInfo]:
    """掃描 .claude/skills/ 下所有含 pyproject.toml 的套件."""

    packages = []

    # 使用共用模組掃描
    scanned = scan_skills_directory(project_root)

    # 轉換為 PackageInfo 格式
    for pkg_name, pkg_info in scanned.items():
        source_path = project_root / pkg_info['path']
        pyproject_path = source_path / 'pyproject.toml'

        # 提取額外資訊
        cli_name = extract_cli_name_from_pyproject(pyproject_path)

        packages.append(PackageInfo(
            name=source_path.name,
            source_path=source_path,
            version=pkg_info['version'],
            package_name=pkg_name,
            cli_name=cli_name,
        ))

    return sorted(packages, key=lambda p: p.name)
```

**變更規模**：從 ~40 行縮減為 ~25 行（因轉換邏輯）

## 技術考量

### Python 版本相容性

- **Hook**: requires-python >= 3.9（pyproject.toml 宣告）
- **CLI**: 使用 Python 3.11+（project-init pyproject.toml）
- **共用模組**：支援 3.9+，使用 tomllib/tomli 相容性代碼

### Import 路徑策略

**Hook 導入方案**（無法直接 import project-init）：
```python
sys.path.insert(0, str(Path(__file__).parent.parent.parent / '.claude' / 'lib'))
from pyproject_scanner import ...
```

**CLI 導入方案**（可直接 import）：
```python
import sys
from pathlib import Path
_lib_path = Path(__file__).parent.parent.parent.parent.parent / '.claude' / 'lib'
sys.path.insert(0, str(_lib_path))
from pyproject_scanner import ...
```
