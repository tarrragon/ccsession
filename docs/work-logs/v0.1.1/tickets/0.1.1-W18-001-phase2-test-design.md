## 測試設計原則

### BDD 測試風格

每個測試應遵循 Given-When-Then 結構：

```python
def test_extract_version_valid():
    # Given: 一個含有版本的 pyproject.toml 檔案
    pyproject_path = fixture_valid_pyproject

    # When: 呼叫 extract_version_from_pyproject()
    version = extract_version_from_pyproject(pyproject_path)

    # Then: 應返回正確的版本字符串
    assert version == "1.0.0"
```

### 錯誤處理測試

每個函數都應有對應的錯誤情況測試：
- 檔案不存在 → 返回 None
- 檔案格式無效 → 返回 None
- 欄位缺失 → 返回 None

### 集成測試關鍵驗證點

1. **格式相容性**：Hook 輸出格式是否與 CLI 期望的格式相同
2. **版本一致性**：Hook 和 CLI 提取的版本字符串是否完全相同
3. **功能保持**：重構前後的功能輸出是否一致

## 測試阻塞器（Blockers）

- 無：所有測試應使用既有的臨時檔案 fixtures，無外部依賴
