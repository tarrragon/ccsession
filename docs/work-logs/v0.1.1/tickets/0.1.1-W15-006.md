## Solution

<!-- To be filled by executing agent -->

修復 is_exempt_path_on_protected_branch() 中的路徑正規化邏輯：(1) import get_project_root；(2) 將絕對路徑轉為相對於專案根目錄的路徑後再比對豁免前綴。原因：Edit 工具傳入絕對路徑（/Users/.../project/.claude/...），lstrip('/') 只移除開頭斜線，結果是 Users/... 而非 .claude/...，導致所有豁免路徑比對失敗。
