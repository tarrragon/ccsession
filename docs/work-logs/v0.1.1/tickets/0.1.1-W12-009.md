# [Layer 3] 0.1.1-W12-009：增強 version-consistency-guard-hook

## 任務來源

Hook 系統需要增強版本一致性檢查，補充「current_version vs 最高工作日誌目錄版本」的檢查功能。

## 背景

現有 `version-consistency-guard-hook.py` 只檢查「舊版本是否有未完成 Ticket」，缺少的功能是：

**當 `docs/work-logs/` 中存在比 `current_version`（來自 `todolist.yaml`）更高的版本目錄時，應輸出警告**。

### 例子

假設：
- `docs/todolist.yaml` 中 `current_version = 0.1.0`
- `docs/work-logs/` 中實際存在 `v0.1.1/` 目錄且包含 Ticket

預期：Hook 應輸出警告，提示用戶更新 `todolist.yaml` 中的 `current_version`

## 功能規格

### 新增函式：`find_highest_worklog_version()`

```python
def find_highest_worklog_version(project_root: Path, logger) -> Optional[str]:
    """Find the highest version directory in docs/work-logs/.

    Returns:
        Version string like '0.1.1', or None if no version directories found
    """
```

**責任**：
- 掃描 `docs/work-logs/v*` 目錄
- 利用現有的 `parse_version_string()` 和 `version_is_older()` 函式進行版本比較
- 返回最高版本字串（不含 `v` 前綴）

### 新增函式：`print_version_mismatch_warning()`

```python
def print_version_mismatch_warning(current_version: str, highest_version: str) -> None:
    """Print warning message about version mismatch."""
```

**責任**：
- 格式化並輸出版本不一致警告
- 包含：發現版本不一致、current_version 值、最高目錄版本、修復建議
- 風格類似現有的 `print_warning()` 函式

### 修改 `main()` 函式

在現有「舊版本未完成 Ticket」檢查之後，新增：

1. 呼叫 `find_highest_worklog_version()` 獲取最高版本
2. 比較 `current_version` vs `highest_worklog_version`
3. 如果 highest > current，呼叫 `print_version_mismatch_warning()`
4. 輸出到 stdout（非阻塞，exit 0）

## 驗收條件

- [ ] 新增 `find_highest_worklog_version()` 函式，正確掃描版本目錄
- [ ] 新增 `print_version_mismatch_warning()` 函式，格式清晰
- [ ] `main()` 中新增版本比較邏輯，放在「舊版本檢查」之後
- [ ] Hook 執行不報錯（目前 current_version=0.1.1，最高目錄也是 v0.1.1，應無警告）
- [ ] 複用現有的 `parse_version_string()` 和 `version_is_older()` 函式
- [ ] 保持現有代碼風格和常數管理一致
- [ ] 不新建檔案，只修改 `version-consistency-guard-hook.py`

## 測試規劃

手動測試場景：

1. **正常情況**（current_version = 最高版本）
   - 執行 Hook，應無版本不一致警告
   - 預期：exit 0，無異常輸出

2. **版本不一致**（current_version < 最高版本）
   - 修改 todolist.yaml 設定 current_version = 0.1.0
   - 執行 Hook，應輸出版本不一致警告
   - 驗證警告包含：current_version、highest_version、修復建議
   - 恢復 todolist.yaml

3. **無版本目錄**
   - 測試空 work-logs 目錄的邊界情況
   - 應正常執行無異常

4. **無效版本目錄名稱**
   - 創建非標準目錄如 `v1.2.3.4.5` 或 `vxyz`
   - Hook 應忽略無法解析的版本目錄

## 約束

- 複用現有版本比較函式，不自行實作
- 警告是非阻塞的（exit 0）
- 不實作自動同步（另外的任務）
- 遵循現有代碼風格（docstring、型別標註、常數管理）
