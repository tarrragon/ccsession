# Execution Log

## Task Summary

修復 Agent tool prompt 欄位未格式化顯示 — 長字串未渲染換行

---

## Problem Analysis

用戶回報：AskUserQuestion tool 的 questions 陣列（深層巢狀）以 compact JSON 單行顯示，可讀性差。與 Agent prompt 問題同源 — W7-001 的巢狀策略（頂層展開，巢狀 compact JSON）對深層結構不足。需重新設計巢狀值的格式化策略，可能需要：(1) 陣列值逐項展開 (2) 巢狀 Map 遞迴展開到 2-3 層 (3) 長文值（如 prompt）渲染換行
## Phase 1 功能規格設計

### 根因分析

問題有兩個層次：

**層次 1（主因）：Go 端截斷導致 JSON 結構破損**

- `serializeToolInput()` 使用 `json.Marshal` 將 toolInput 物件序列化為 JSON 字串
- `MaxToolInputLength = 2000` bytes 截斷限制
- Agent tool 的 prompt 通常遠超 2000 bytes，截斷後 JSON 結構不完整
- Dart 端 `_decodeToObject` 和 `formatJsonObject` 的 `json.decode` 均失敗
- Fallback 路徑 `value.toString()` 回傳原始截斷字串，**未經 `unescapeForDisplay` 處理**
- 結果：字面 `\n`（反斜線 + n）未被渲染為換行

**層次 2（次因）：formatJsonObject 的 catch 路徑缺少 unescape**

- `formatJsonObject` 第 26-29 行的 `FormatException` 和 `JsonUnsupportedObjectError` catch 路徑
- 直接回傳 `value.toString()`，未套用 `unescapeForDisplay`
- 即使不是截斷問題，任何解碼失敗的情況都不會 unescape

### 修復方案（最小修改）

**方案 A（推薦）：修復 Dart 端 fallback 路徑 — 套用 unescape**

修改位置：`json_format_helper.dart`

1. `formatJsonObject` 的兩個 catch 路徑加上 `unescapeForDisplay`：
   - 第 27 行 `return value.toString()` → `return unescapeForDisplay(value.toString())`
   - 第 29 行同上

這是最小修改，解決「截斷後字面 \n 不渲染」的直接問題。

2. 選擇性：`_formatSingleEntry` 第 84 行 Map/List compact JSON 也加 unescape：
   - `return '$key: ${unescapeForDisplay(json.encode(val))}';`
   - 解決 AskUserQuestion 等巢狀值中的跳脫字元問題

**方案 B（不推薦）：提高 Go 端 MaxToolInputLength**

- 治標不治本，仍需方案 A 修復 fallback 路徑
- 增加記憶體使用

### 設計決策

採用方案 A，只修改 `json_format_helper.dart`：
- `formatJsonObject` 的 catch 路徑加 `unescapeForDisplay`
- `_formatSingleEntry` 的 Map/List 路徑加 `unescapeForDisplay`

### 介面定義

無新函式、無新類別。僅修改現有函式內部邏輯，公開介面不變。

### 驗收標準（Given-When-Then）

場景 1: Agent tool prompt 截斷後的換行渲染
Given: Agent tool_use 事件，prompt 值超過 2000 bytes 被 Go 端截斷（JSON 結構不完整）
When: formatKeyValue 處理此 toolInput
Then: prompt 中的 \n 渲染為換行符，不顯示為字面反斜線 + n

場景 2: Agent tool prompt 未截斷的正常渲染
Given: Agent tool_use 事件，prompt 值未超過 2000 bytes
When: formatKeyValue 處理此 toolInput
Then: prompt 中的換行符正確顯示

場景 3: formatJsonObject fallback 路徑的 unescape
Given: 任何無法 JSON 解碼的字串值
When: formatJsonObject 處理此值
Then: 回傳值經過 unescapeForDisplay 處理

場景 4: 巢狀 Map/List 值的 unescape
Given: toolInput 為 Map，某個 value 是 Map 或 List
When: _formatSingleEntry 格式化此項目
Then: compact JSON 輸出經過 unescapeForDisplay 處理
