### Phase 1: 重構計劃

#### 重構動機與目標

**問題 1**: `flattenGroups`（session_list_items.dart:46-84）認知負擔指數 18（>15 必須重構閾值），35 行（>30 行上限）。函式同時負責迴圈遍歷、摺疊判斷、分頁計算、項目產出四個職責。

**問題 2**: 預設頁碼 Map `{active: 0, idle: 0, completed: 0}` 和預設展開 Map 在 `SessionGroupUiState` 建構式和 `resetAllPages()` 中重複定義，違反 DRY。

**問題 3**: `session_group_header.dart` 中 `size: 20` 和 `width: 4` 為魔法數字，違反常數管理規範。

**目標狀態**:
- `flattenGroups` 認知負擔指數降至 < 10
- 預設 Map 單一來源（靜態常數）
- Header 魔法數字提取至 `SessionListConstants`

#### 影響範圍分析

| 檔案 | 變更類型 |
|------|---------|
| `session_list_items.dart` | 拆分函式（內部重構） |

| `session_group_ui_notifier.dart` | `resetAllPages()` 改引用常數 |
| `session_group_header.dart` | 魔法數字改引用常數 |
| `session_list_constants.dart` | 新增 2 個常數 |

**行為變更**: 無。所有變更為純結構重構。

- **預期無測試需修改**: 測試透過公開函式 `flattenGroups` 驗證行為，不依賴內部結構
