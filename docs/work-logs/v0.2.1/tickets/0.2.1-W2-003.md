## 功能規格設計

### 1. 後端變更：Summary 每次更新

**檔案**：server/session_registry.go:85-87

**現行邏輯**：
```go
if session.EventCount == 1 && event.Type == EventTypeUser {
    session.Summary = truncateString(event.Content.Text, MaxSummaryLength)
}
```

**新邏輯**：
```go
if event.Type == EventTypeUser {
    session.Summary = truncateString(event.Content.Text, MaxSummaryLength)
}
```

移除 EventCount==1 條件。每次收到 user 類型事件，都用最新內容覆蓋 Summary。截斷長度維持 MaxSummaryLength（100 字元）不變。

**邊界條件**：
- 空 Content.Text：truncateString 回傳空字串，Summary 被設為空（不影響前端 fallback）
- 非 user 事件（assistant/tool_result 等）：不更新 Summary，維持最後一個 user 訊息

### 2. 前端變更：_sessionTitle 加 [Agent] 前綴

**檔案**：ui/.../session_list_tile.dart

**新邏輯**：
```dart
String _sessionTitle(SessionInfo session) {
  final title = _buildTitleText(session);
  if (session.agentType.isNotEmpty) {
    return '${SessionListConstants.agentTitlePrefix} $title';
  }
  return title;
}

String _buildTitleText(SessionInfo session) {
  // 原有 fallback 邏輯不變：summary > lastMessage 前 N 字 > ID 前 8 字
}
```

**判斷 Agent 的依據**：`session.agentType.isNotEmpty`。agentType 由後端 Hook 事件（SubagentStart）填充，只有 agent session 才有值。

**常數新增**（session_list_constants.dart）：
```dart
static const agentTitlePrefix = '[Agent]';
```

### 3. 前端變更：_sessionSubtitle 移除 projectName

**現行邏輯**：顯示 projectName / agentName
**新邏輯**：只顯示 agentName（因為有專案頁籤，projectName 已冗餘）

```dart
String _sessionSubtitle(SessionInfo session) {
  return session.agentName; // v0.3 前永遠為空字串

```

注意：agentName 在 v0.2 永遠為空字串（見 session_registry_models.go:36-38 註解），所以副標題目前會是空字串。這是預期行為——等 v0.3 實作 agentName 填充後自動生效。
