### 3. WP-Flutter：標題前綴 + 副標題簡化

#### 3.1 虛擬碼

```
FUNCTION sessionTitle(session):
    titleText = buildTitleText(session)
    IF session.agentType IS NOT EMPTY:
        RETURN AGENT_PREFIX + " " + titleText
    END IF
    RETURN titleText
END FUNCTION

FUNCTION buildTitleText(session):
    // 既有 fallback 邏輯不變
    IF session.summary IS NOT EMPTY:
        RETURN session.summary
    IF session.lastMessage IS NOT EMPTY:
        RETURN TRUNCATE(session.lastMessage, SUMMARY_FALLBACK_MAX_LENGTH)
    RETURN SUBSTRING(session.id, 0, MIN(LENGTH(session.id), SESSION_ID_FALLBACK_LENGTH))
END FUNCTION

FUNCTION sessionSubtitle(session):
    RETURN session.agentName   // 移除 projectName 邏輯
END FUNCTION
```

### 5. 資料流程圖

```
Go 後端（WP-Go）:
  JSONL user event → UpsertFromSessionEvent → Summary = 最新 user text（截斷）
                                              ↑ 每次覆蓋，不再限首次

JSON WebSocket（不變）:
  SessionInfo { summary, agentType, lastMessage, id, agentName, projectPath }

Flutter 前端（WP-Flutter）:
  SessionInfo → _sessionTitle → agentType 非空? → "[Agent] " + _buildTitleText
                                                → _buildTitleText (fallback 鏈)
              → _sessionSubtitle → agentName (移除 projectName)
```

### 6. 控制流程圖

```
_sessionTitle(session):

    +-- 否 --> return titleText

_buildTitleText(session):        [既有邏輯不變]

    +-- 否 --> lastMessage 非空?
```
