# v0.2.1 工作日誌

## 版本目標

Flutter Frontend 基本連線：Flutter app 能連上 Go Backend，顯示 session 列表，點進去看到即時對話內容。最小 UI，不需要任何介面優化。

## 版本里程碑

打開 Flutter app：
- 看到本機正在進行的 Claude Code session 列表（session ID、狀態、最後活動時間）
- 點進某個 session，看到即時滾動的對話內容（user 訊息、assistant 回應、tool_use）
- session 狀態變化（active → idle → completed）即時反映在列表

## 前置條件

- v0.2.0 完成（Go Backend 可正常運作）

## Wave 規劃

### Wave 1: Flutter Core

WebSocket 客戶端和基本 UI 骨架。

| Ticket | 標題 | 說明 |
|--------|------|------|
| W1-001 | Flutter WebSocket 客戶端 | 建立 WebSocket 連線、訊息解析、基本連線狀態管理 |
| W1-002 | Session 列表頁面 | 顯示所有 session，包含狀態標籤和基本 metadata |

**Wave 1 產出**：app 可連線並看到 session 列表

### Wave 2: 對話詳情

Session 對話內容渲染。

| Ticket | 標題 | 說明 |
|--------|------|------|
| W2-001 | 對話詳情頁面 | 訂閱指定 session，渲染 user/assistant/tool_use 訊息，即時追加新訊息 |
| W2-002 | 歷史訊息載入 | `get_session_history` 實作，首次開啟載入最新 100 筆，支援向上捲動載入更早訊息 |

**Wave 2 產出**：完整的 MVP —— 能看到 session 列表和對話內容
