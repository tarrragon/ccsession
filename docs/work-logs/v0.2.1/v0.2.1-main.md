## 版本里程碑

打開 Flutter app：
- 看到本機正在進行的 Claude Code session 列表（session ID、狀態、最後活動時間）
- 點進某個 session，看到即時滾動的對話內容（user 訊息、assistant 回應、tool_use）
- session 狀態變化（active → idle → completed）即時反映在列表

## v0.3 前置預留要求（來源：0.2.0-W5-001 分析）

> v0.3 Agent Graph 需要 `Stream<AgentMessage>` 驅動動畫。以下預留要求確保 v0.2.1 的架構設計不阻塞 v0.3 接入。

### W1-001 設計約束（強制）

| # | 預留要求 | 說明 |
|---|---------|------|
| 1 | WebSocket 事件層以 `Stream<SessionEvent>` 形式暴露 | v0.3 可透過 `.where().map()` 過濾為 `Stream<AgentMessage>`，零改動接入 |
| 2 | 定義 `SessionEventRepository` 抽象介面 | `Stream<SessionEvent> get events` + `subscribe/unsubscribe`，解耦元件與 WebSocket 實作 |
| 3 | WebSocket 訊息解析包含 `default` 分支 | 處理未知事件類型（v0.3 新增 `agent_status_change`、`agent_message`），避免 runtime 例外 |

### 架構選型建議

| 選項 | v0.3 接入難度 | 說明 |
|------|-------------|------|
| Riverpod `StreamProvider` | 低 | `.stream` 屬性天然相容 |
| `StreamController<SessionEvent>` | 低 | 直接暴露 `.stream` |
| `ChangeNotifier` / `ValueNotifier` | 高 | 需額外橋接層，不建議 |

### SessionEvent Dart 模型預留欄位

```dart
class SessionEvent {
  // 現有欄位...
  final String? agentId;  // v0.3 預留：產生此事件的 agent ID（v0.2 多數為 null）
}
```
