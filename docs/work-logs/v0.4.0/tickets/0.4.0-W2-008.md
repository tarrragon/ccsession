## 根因分析

### 問題 1：description 觸發詞缺少關鍵場景
Skill description 用「多角度快速評估」「並行掃描」，但用戶和 PM 使用的是「多視角審核」「code review」。詞彙不對齊導致 Skill 系統不觸發。

1. Skill 觸發詞覆蓋不足（主因）
2. PM 未走標準流程，手動派發取代制度化檢查（輔因）
