## Solution

### 實作概況

已成功實作 PhaseContractValidator 四層驗證機制和 phase_complete.py 整合模組。

### 實作檔案

1. **`.claude/hooks/phase-contract-validator-hook.py`**（915 行）
   - `ValidationResult` dataclass：驗證結果容器
     - `errors: list[str]` - Layer 1-3 失敗（阻止轉移）
     - `warnings: list[str]` - Layer 4 失敗或 legacy 降級（提示）
     - `infos: list[str]` - 資訊性提示
     - `can_proceed: bool` - 是否允許 Phase 轉移（errors 為空時為 True）
   
   - `PhaseContractValidator` 類別：Phase Contract 驗證器
     - `validate(ticket_id, phase, ticket_dir)` - 執行四層驗證
     - `_check_existence()` - Layer 1：必要 artifact 檔案存在
     - `_check_format()` - Layer 2：frontmatter YAML 格式正確
     - `_check_structure()` - Layer 3：必要 Section 存在
     - `_check_content()` - Layer 4：Section 內容符合規範（始終 WARNING）
     - `_is_legacy_artifact()` - 判定是否為 legacy 文件（基於 mtime 和 frontmatter）
     - `_resolve_artifact_path()` - 前綴匹配解析 path_pattern（IMP-011 核心）

2. **`.claude/skills/tdd/commands/phase_complete.py`**（156 行）
   - `complete_phase(ticket_id, phase, ticket_dir, contracts_path)` - 整合函式
     - 載入 contracts.yaml
     - 呼叫 PhaseContractValidator.validate()
     - 輸出驗證結果（[ERROR] 前綴 + [WARNING] 前綴）
     - 將驗證結果寫入 Ticket execution log
     - 返回 bool：errors 存在時 False，僅 warnings 時 True
   
   - `_write_validation_log()` - 輔助函式，追加驗證結果到 Ticket execution log

### 四層驗證實作細節

| Layer | 檢查項 | 新文件行為 | Legacy 行為 | 實作位置 |
|-------|--------|----------|-----------|---------|
| 1 | 必要 artifact 檔案存在 | ERROR | ERROR | `_check_existence()` |
| 2 | frontmatter YAML 格式正確 | ERROR | WARNING | `_check_format()` |
| 3 | 必要 Section 存在 | ERROR | WARNING | `_check_structure()` |
| 4 | Section 內容符合規範 | WARNING | INFO | `_check_content()` |
