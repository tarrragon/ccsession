---

## Problem Analysis

整合測試發現 002.1/002.2 產出物的三個設計缺口：

1. **Direction regex 雙重轉義**（validator hook L345）：raw string 中 `[\\w.-]` 被解析為字面 `\w` 而非詞字元類，導致 `to-sibling:0.31.1-W3-002` 格式無法匹配
2. **Phase 2 缺少替代後綴**（contracts.yaml）：`-phase2-tests` 後綴不在 `alternate_patterns`，導致 2 個現存文件產生 ERROR
3. **Phase 3b source-code artifact 不可達**（contracts.yaml）：`required: true` 的 `source-code` artifact（`ui/lib/**/*.dart`）在 ticket_dir 中找不到，Layer 1 存在性驗證 ERROR 且不受 legacy 降級保護

---

## Solution

三項修正：

| # | 修正 | 檔案 | 變更 |
|---|------|------|------|
| 1 | Direction regex 修正 | `phase-contract-validator-hook.py` L345 | `[\\w.-]` → `[\w.-]` |
| 2 | Phase 2 替代後綴 | `contracts.yaml` Phase 2 alternates | 新增 `{ticket-id}-phase2-tests.md` |
| 3 | source-code 改為可選 | `contracts.yaml` Phase 3b + validator `_check_existence` | `required: false` + 邏輯判斷 |
