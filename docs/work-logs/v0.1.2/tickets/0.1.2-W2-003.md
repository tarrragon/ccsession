## Solution

### Bug 1：blockedBy 驗證在 save_ticket() 後執行

**修正**：
- 新增 `_validate_blocked_by_references()` 私有函式封裝驗證邏輯
- 驗證移至 save_ticket() 之前（第 305 行）
- 驗證失敗時 return 1（阻止建立），而非只輸出 WARNING
- 在 command_lifecycle_messages.py 新增 `BLOCKED_BY_NOT_FOUND` 常數

### Bug 2：acceptance_auditor.py Step 4 正則表達式問題

**修正**：
- 簡化正則表達式，改用非捕獲組 `(?:##|###)` 替代 OR 操作符
- 確保 group(1) 總是捕獲內容部分，不會因分支選擇而返回 None
- 新增 .strip() 處理前後空白

### 問題 3：blockedBy 警告硬編碼 + 驗證未封裝

**修正**：
- 已在 Bug 1 中解決（使用 CreateMessages.BLOCKED_BY_NOT_FOUND）
- 驗證邏輯已封裝為 `_validate_blocked_by_references()` 私有函式

### 問題 4：VAGUE_ACCEPTANCE_WARNING 死程式碼

**修正**：
- 在 `_print_create_checklist()` 中新增邏輯以偵測含糊驗收條件
- 無論是否使用預設驗收條件都執行檢查
- import detect_vague_acceptance 並調用

### 問題 5：SEC/PERF/INFRA 類型集合不一致

**修正**：
- 從 DEFAULT_ACCEPTANCE_CRITERIA 移除 SEC、PERF、INFRA 三個未在 TICKET_TYPES 中註冊的類型
- 加入註解說明原因：「這些類型未在 TICKET_TYPES 中定義，若需支援請先在 constants.py 註冊」

### 問題 6：ticket_builder.py docstring 過時

**狀態**：docstring 已是現狀態，無需更新

### 問題 7：Stop hook 版本解析重複

**修正**：
- 新增 `_get_ticket_file_path()` 共用函式
- 重構 `is_ticket_recently_started()` 和 `is_ticket_completed()` 以使用共用函式
- 消除約 50 行重複程式碼

### 問題 8：deprecated scan_in_progress_tickets

**修正**：
- 將函式體簡化為只保留 docstring 和 `return []`
- 確認無呼叫者（僅在註釋中提及）
