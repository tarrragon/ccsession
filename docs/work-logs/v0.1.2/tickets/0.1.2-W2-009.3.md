# Execution Log

## Task Summary

重構 架構層級邊界和錯誤處理（跨層 import、時區、Section 匹配、靜默失敗）

---

## Problem Analysis

### 4 項架構與品質問題

#### 1. 跨層 import 違規（架構層級邊界）
- **位置**：`.claude/skills/tdd/commands/phase_complete.py:28`
- **問題**：`sys.path.insert()` 直接導入 Hook 層模組 `phase_contract_validator_hook`
- **根因**：Skill 層（`.claude/skills/`）和 Hook 層（`.claude/hooks/`）應各自獨立，跨層通信應透過 `.claude/lib/` 共用模組
- **影響**：架構分層模糊化，維護困難

#### 2. 時區處理不一致（IMP-044 完善）
- **位置**：`.claude/hooks/phase-contract-validator-hook.py:386`
- **問題**：`_is_legacy_artifact()` 使用 `datetime.fromtimestamp()` 建立本地時間，而全系統其他 Hook 都用 `datetime.now().isoformat()`（UTC）
- **根因**：時區未明確設定，導致不同環境結果可能不同
- **影響**：Legacy 判定在不同時區可能不一致

#### 3. Section 匹配不完整（IMP-045 新增）
- **位置**：`.claude/hooks/phase-contract-validator-hook.py:311-327`
- **問題**：Section 匹配僅支援精確名稱，不支援替代名稱（如 Phase 3b "測試結果" 的替代名稱 "Test Results"）
- **根因**：contracts.yaml 定義了 Section 替代名稱（alternate_names），但驗證邏輯未實現
- **影響**：不同格式化方式的 Ticket 報告無法驗證通過

#### 4. Exception 靜默失敗違反品質基線規則 4
- **位置**：
  - `.claude/hooks/phase-contract-validator-hook.py:77-90`（`_load_contracts()`）
  - `.claude/hooks/phase-contract-validator-hook.py:234-249`（`_read_file_safely()`）
  - `.claude/hooks/phase-contract-validator-hook.py:401-408`（`_is_legacy_artifact()`）
- **問題**：`except` 區塊只返回 None 或發 raise，未輸出 stderr，導致異常資訊遺失
- **根因**：Exception 處理未遵循品質基線規則 4 的雙通道要求（stderr + 日誌）
- **影響**：異常診斷困難，靜默失敗難以追蹤

---

## Solution

### 修正概述

| 問題 | 修正方式 | 檔案 |
|------|---------|------|
| 跨層 import | 移動驗證器到 `.claude/lib/`，改用 `from phase_contract_validator import ...` | `.claude/lib/phase_contract_validator.py`（新），`.claude/skills/tdd/commands/phase_complete.py` |
| 時區不一致 | 統一使用 `datetime.fromtimestamp(file_mtime, tz=timezone.utc)` + UTC 邊界設定 | `.claude/hooks/phase-contract-validator-hook.py:386-408` |
| Section 匹配 | 實現 `alternate_names` 邏輯，從 contracts.yaml 讀取替代名稱並執行匹配 | `.claude/hooks/phase-contract-validator-hook.py:295-347`，`.claude/tdd/contracts.yaml` |
| 靜默失敗 | 在 except 區塊加入 `sys.stderr.write()`，實現雙通道輸出 | `.claude/hooks/phase-contract-validator-hook.py` 多處 |

### 核心修改清單

1. **架構重構**：
   - 建立 `.claude/lib/phase_contract_validator.py`（從 Hook 層提昇至共用層）
   - 修改 `phase_complete.py` 導入路徑：`sys.path.insert(0, ".claude/lib")`

2. **時區修正**：
   - `_is_legacy_artifact()` 改用 `datetime.fromtimestamp(file_mtime, tz=timezone.utc)`
   - `threshold_datetime` 設定 `tzinfo=timezone.utc` 確保一致性

3. **Section 匹配擴展**：
   - `.claude/tdd/contracts.yaml` Phase 3b 的 "實作概況" 和 "測試結果" Section 新增 `alternate_names` 欄位
   - `_check_structure()` 檢查邏輯改為：先比對精確名稱，再查詢 `alternate_names` 集合

4. **Exception 雙通道輸出**：
   - `_load_contracts()` 的 YAML 錯誤：加 `sys.stderr.write(f"[ERROR] {error_msg}\n")`
   - `_read_file_safely()` 的 OSError：加 `sys.stderr.write(f"[ERROR] {error_msg}\n")`
   - `_is_legacy_artifact()` 的 ValueError：加 `sys.stderr.write(f"[WARNING] {error_msg}\n")`
