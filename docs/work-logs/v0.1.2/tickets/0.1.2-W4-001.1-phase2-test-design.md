本 Ticket 屬於 **IMP（品質修正）** 類型，修改目標是函式簽名與邏輯，非外部 API 變更。

| 層級 | 測試類型 | 決策 |

| 依賴類型 | Mock 策略 | 理由 |

### 問題 3：`_build_decision_tree_path` 7-case 簡化為 3 分支

#### 行為鏈式推演

**分支 1：豁免且無參數 → 返回 None**

```
Given: is_child=True OR ticket_type="DOC"（豁免條件）
  Then (前置驗證): entry, decision, rationale 均為 None

When: _build_decision_tree_path() 被呼叫
  Then: 不執行參數驗證（guard clause 直接返回）
  Then: 返回 None（無例外拋出）
```

**分支 2：完整三參數 → 驗證後返回字典**

```
Given: entry, decision, rationale 都非空字串（完整三參數）
  Then (前置驗證): _validate_decision_tree_params() 會被呼叫

When: 驗證通過
  Then: 返回字典（entry_point, final_decision, rationale）
  Then: 無例外拋出

When: 驗證失敗（如空字串）
  Then: ValueError 被拋出，訊息為「決策樹參數驗證失敗」
```

**分支 3：部分參數或非豁免無參數 → 輸出錯誤 + raise**

```
Given: provided_count in {1, 2} OR (provided_count == 0 AND is_exempted == False)
  Then (前置驗證): 部分或無參數

When: _build_decision_tree_path() 被呼叫
  Then: format_error() 被呼叫（輸出對應錯誤訊息）
  Then: ValueError 被拋出，訊息為「決策樹參數不完整」
```
