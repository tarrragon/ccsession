修改 normalize_path() 函式，從 skip 策略改用 stack pop 策略正確消除 '..' 序列：

改進方式：
- 舊方法：遇到 '..' 時直接跳過（continue），導致 a/../b → a/b（錯誤）
- 新方法：使用 stack，遇到 '..' 時 pop 前面的路徑部分，實現正確的路徑遍歷消除

測試驗證：
- 所有 44 個既有測試通過
- 新增 7 個 '..' 遍歷邊界測試案例，全部通過
- 覆蓋場景包括：
  1. 單層 '..' 遍歷：a/../b → b
  2. 前綴 '..' 遍歷：../config → config
  3. 多層 '..' 遍歷：a/b/../../c → c
  4. 巢狀 '..' 遍歷：a/b/../c/d/../../e → a/e
  5. 超過深度的 '..' 遍歷：../../../a → a
  6. '..' 與 './' 組合：./a/../b → b
  7. '..' 與其他規則組合：.\A\..//B/ → b
