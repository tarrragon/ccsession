## 版本里程碑

系統在以下真實場景穩定運作：
- 同時執行 3-5 個 Claude Code agent，session 列表正確反映所有狀態
- Backend 重啟後，Frontend 自動重連並恢復狀態
- 在 Claude Code < v2.1.63 的環境下，自動降級到純 JSONL watching 模式，不崩潰
- 連續運作 30+ 分鐘無記憶體洩漏或連線異常

## Wave 規劃

### Wave 1: 端對端整合驗證

在真實 Claude Code 環境下的全面測試。

| Ticket | 標題 | 說明 |
|--------|------|------|
| W1-001 | 端對端整合測試 | 真實場景：啟動多個 Claude Code session，驗證 HTTP Hooks + JSONL 事件融合正確性 |
| W1-002 | 邊界情境處理 | JSONL 不完整行、重複事件、session 意外終止等 edge case 驗證 |

**Wave 1 產出**：識別所有真實場景問題，建立修復 Ticket

### Wave 2: 穩定化

容錯和恢復機制。

| Ticket | 標題 | 說明 |
|--------|------|------|
| W2-001 | HTTP Hooks 版本降級策略 | 系統啟動時檢測 Claude Code 版本，< v2.1.63 時自動禁用 HTTP Hooks，完全回退 JSONL watching |
| W2-002 | WebSocket 斷線重連 | Frontend 斷線後自動重連，重連後請求 session_list 恢復狀態 |
| W2-003 | 基本效能驗證 | 多 session 並發事件下的延遲和記憶體使用情況 |

**Wave 2 產出**：系統具備基本的容錯和自我恢復能力
