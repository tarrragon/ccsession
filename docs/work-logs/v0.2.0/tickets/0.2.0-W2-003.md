改善 ticket create 的子任務建立引導和多值參數 help 說明

---

## Problem Analysis

### 問題根因

PM 使用 ticket create 建立子任務時連續 3 次失敗：
1. 嘗試 `--id "0.2.0-W2-001.1"` -- 參數不存在（應用 `--parent`）
2. 嘗試 `--seq 001.1` -- 子任務序號格式不被接受（應省略，由 `--parent` 自動產生）
3. 多值參數 `--acceptance "A" "B"` 被 shell 解析為位置參數（應用 `--acceptance "A" --acceptance "B"` 或 `"A|B"`）

根因：SKILL 引導不足，PM 無法從 help 或 SKILL.md 推斷正確用法，導致幻覺不存在的參數。

### 影響範圍

- .claude/skills/ticket/SKILL.md（缺少子任務建立範例）
- ticket create --help 輸出（多值參數格式不明確）
- argparse 錯誤訊息（不友善，無格式提示）
