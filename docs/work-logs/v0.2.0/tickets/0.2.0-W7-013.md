## Problem Analysis

根因：SubagentStart HTTP Hook 的 session_id 是主 session ID（非 subagent），registry 用錯誤 key 建立記錄。SubagentStop 的 agent_transcript_path 包含正確的 subagent JSONL 路徑但完全未被使用。影響：session_registry.go(L128-155)、event_dispatcher.go(L202-252)、file_watcher.go(L177-195)。修復方向：(A) SubagentStop 從 TranscriptPath 提取 subagent UUID 作為 registry key (B) SubagentStart 改為只更新主 session 狀態 (C) FileWatcher 新目錄補掃現有檔案。
