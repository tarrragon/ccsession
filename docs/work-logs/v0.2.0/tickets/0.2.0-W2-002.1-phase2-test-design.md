## 1. 測試策略規劃

### 1.1 分層測試決策

| 層級 | 測試對象 | 測試類型 | 理由 |
|------|---------|---------|------|
| Domain Model | freezed 資料模型（SessionInfo, SessionEvent 等） | 單元測試 | Layer 5 純資料轉換，無外部依賴 |
| Domain Model | WsConnectionState enum | 單元測試 | 狀態定義驗證 |
| Domain Model | ReconnectStrategy | 單元測試 | Layer 5 純計算邏輯 |
| Infrastructure | WebSocketServiceImpl | 單元測試（Sociable） | Layer 3 UseCase 等級，Mock WebSocketChannel |
| Provider | Riverpod provider | 整合測試 | Layer 2 行為層，驗證 provider 連接 |

### 1.2 Mock 策略（Sociable Unit Tests）

| 依賴 | Mock 策略 | 理由 |
|------|----------|------|
| `WebSocketChannel` | Mock | 外部依賴（網路 I/O） |
| `WebSocketChannel.sink` | Mock | 外部依賴 |
| `WebSocketChannel.stream` | Mock（StreamController） | 外部依賴 |
| `Timer` | FakeAsync | 外部依賴（時間） |
| `ReconnectStrategy` | 不 Mock | 內層邏輯，使用真實物件 |
| `ServerMessage` / `SessionInfo` 等 freezed model | 不 Mock | Domain Entity，直接使用 |
| `ClientMessage` | 不 Mock | Value Object |

### 1.3 測試工具

| 工具 | 用途 |
|------|------|
| `flutter_test` | 測試框架 |
| `mocktail` | Mock 物件（無需 code gen） |
| `fake_async` | 控制 Timer 和 Future.delayed |
| `stream_channel` | 建立 mock WebSocket stream |

### TG-01: SessionInfo JSON 序列化 (`session_info_test.dart`)

**測試層級**: 單元測試（Domain Model）

#### TC-01-01: 完整欄位 JSON 反序列化（正常流程）

```
Given: 一個包含所有欄位的 Go Backend SessionInfo JSON map
  {
    "id": "session-abc",
    "projectPath": "/path/to/project",
    "summary": "Test session",
    "status": "active",
    "firstEventAt": "2026-03-25T10:00:00Z",
    "lastEventAt": "2026-03-25T10:05:00Z",
    "firstUserMessageAt": "2026-03-25T10:01:00Z",
    "eventCount": 42,
    "agentId": "agent-1",
    "agentType": "main",
    "lastMessage": "Hello",
    "parentAgentId": "",
    "agentName": "claude"
  }
Then（前置驗證）: JSON map 非 null 且包含 "id" key
When: SessionInfo.fromJson(json) 被呼叫
Then: 回傳 SessionInfo 物件
      且 id == "session-abc"
      且 status == SessionStatus.active
      且 eventCount == 42
      且 firstUserMessageAt != null
```

#### TC-01-02: 最小欄位 JSON 反序列化 — @Default 填入預設值（邊界條件）

```
Given: 僅包含必填欄位的 JSON map（id, projectPath, status, firstEventAt, lastEventAt）
Then（前置驗證）: JSON map 不包含 "summary", "eventCount", "agentId" 等可選欄位
When: SessionInfo.fromJson(json) 被呼叫
Then: 回傳 SessionInfo 物件
      且 summary == ''（@Default）
      且 eventCount == 0（@Default）
      且 agentId == ''（@Default）
      且 firstUserMessageAt == null
```

#### TC-01-03: SessionStatus enum JSON 對應（正常流程）

```
Given: 三個 JSON map 分別包含 status: "active", "idle", "completed"
When: SessionInfo.fromJson(json) 對每個 map 被呼叫
Then: 回傳物件的 status 分別為 SessionStatus.active, .idle, .completed
```

#### TC-01-04: SessionInfo toJson 往返（正常流程）

```
Given: 一個 SessionInfo 物件（完整欄位）
When: sessionInfo.toJson() 被呼叫，再以 SessionInfo.fromJson(result) 反序列化
Then: 往返後的物件與原始物件相等（== 比較為 true）
```

#### TC-01-05: freezed equality 和 copyWith（正常流程）

```
Given: 兩個相同參數建構的 SessionInfo 物件
When: 比較 a == b
Then: 結果為 true

Given: 一個 SessionInfo 物件
When: 呼叫 copyWith(summary: 'new')
Then: 新物件 summary == 'new'，其餘欄位不變
```
