# Execution Log

## Task Summary

改善 check-acceptance 子命令的參數引導 — index 為 positional argument 但 SKILL 未明確說明

---

## Problem Analysis

### 問題根因

`check-acceptance` 子命令的錯誤訊息和文件中缺乏明確的參數說明。當用戶未提供 index 時，錯誤訊息只簡單地說「必須提供 index 或使用 --all 參數」，沒有展示具體的使用範例。此外，PM 在閱讀 SKILL.md 時不清楚 index 是 positional argument（位置參數）而非選項形式（--index）。

### 影響範圍

- 影響所有使用 `ticket track check-acceptance <id>` 命令的用戶
- 相關檔案：
  - `ticket_system/lib/messages.py`（錯誤訊息）
  - `references/track-command.md`（操作手冊）
  - `SKILL.md`（SKILL 說明文件）

### 相關 Error Pattern

無已知相關錯誤模式，但屬於「CLI 引導不足」類問題（IMP-033 同類）。

---

## Solution

### 1. 改善 messages.py 的錯誤訊息（行 59）

將簡單的錯誤訊息擴展為包含完整用法示範和提示的多行訊息：

```python
CHECK_ACCEPTANCE_MISSING_INDEX = (
    "[Error] 必須提供 index 或使用 --all 參數\n"
    "\n"
    "用法：\n"
    "  ticket track check-acceptance <id> --all          # 勾選全部驗收條件\n"
    "  ticket track check-acceptance <id> 1 2 3          # 勾選第 1、2、3 項\n"
    "  ticket track check-acceptance <id> 1 --uncheck    # 取消勾選第 1 項\n"
    "\n"
    "提示：先用 ticket track query <id> 查看驗收條件清單和編號"
)
```

優點：用戶看到錯誤時，立即知道如何正確使用該命令。

### 2. 補充 track-command.md 的 check-acceptance 用法（行 71-74）

將原有的單行說明改為多行範例，清楚展示三種常見用法：

```bash
# 勾選驗收條件
/ticket track check-acceptance <id> --all              # 勾選全部驗收條件
/ticket track check-acceptance <id> 1 2 3              # 勾選指定項（index 從 1 開始）
/ticket track check-acceptance <id> 1 --uncheck        # 取消勾選第 1 項
```

優點：users 在查閱 track-command.md 時，一眼看到 index 是 positional argument（不加 --）。

### 3. SKILL.md 新增 check-acceptance 注意事項（行 244）

在 track 子命令的注意事項區塊新增第三項提示：

```
> **注意**：`check-acceptance` 必須指定 `--all`（勾選全部）或 index（如 `1 2 3`，從 1 開始編號）：
> `ticket track check-acceptance <id> --all` 或 `ticket track check-acceptance <id> 1 2 3`。
> 先用 `ticket track query <id>` 查看驗收條件清單和編號。
```

優點：PM 在閱讀 SKILL.md 時，直接看到該命令的正確語法和前置步驟。
