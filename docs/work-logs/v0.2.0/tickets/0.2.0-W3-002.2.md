## Solution

### 實現概要

#### 1. CommandRunner 介面與 defaultCommandRunner
- CommandRunner 介面抽象外部命令執行，支援測試時注入 mock
- defaultCommandRunner 實現實際的命令執行（使用 exec.CommandContext）

#### 2. DetectClaudeVersion 函式
- 執行 `claude --version` 並解析版本號
- 實現三段版本決策邏輯：
  - < v2.1.63 → HTTPHooksEnabled=false, FullFeaturesAvailable=false
  - [v2.1.63, v2.1.69) → HTTPHooksEnabled=true, FullFeaturesAvailable=false
  - >= v2.1.69 → HTTPHooksEnabled=true, FullFeaturesAvailable=true
- 全失敗情境安全降級（返回空 VersionConfig），記錄結構化日誌
- 支援逾時、命令不存在、解析失敗等邊界情況

#### 3. newDisabledHooksHandler 函式
- HTTP 501 Not Implemented handler
- JSON 回應包含升級提示訊息
- 結構化日誌記錄，包含 layer 欄位

#### 4. main.go 整合
- 版本偵測在所有初始化之前執行
- 條件路由：HTTPHooksEnabled → 實際 handler；否則 → 降級 handler
- FileWatcher 始終啟動（不受版本限制）

#### 5. 訊息常數
- 在 version_detect_messages.go 中集中定義所有日誌訊息常數
- 符合專案命名慣例和集中管理規範
