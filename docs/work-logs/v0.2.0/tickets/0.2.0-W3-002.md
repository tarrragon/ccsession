### Phase 4b 重構執行

#### 必須修復（三人組共識）

1. **超時偵測邏輯缺陷**
   - 問題：`ctx.Err() == context.DeadlineExceeded` 判斷在生產環境可能不觸發，因為 `exec.CommandContext` 超時時回傳的 err 可能是 `*exec.ExitError` 而非直接的 `context.DeadlineExceeded`
   - 修復：改用 `ctx.Err() == context.DeadlineExceeded || errors.Is(err, context.DeadlineExceeded)` 同時檢查
   - 位置：version_detect.go 第 119-121 行

2. **硬編碼版本字串消除**
   - 問題：`newDisabledHooksHandler` 中硬編碼 `"HTTP Hooks not available: requires Claude Code v2.1.63+"`，與 `MinVersionHTTPHooks` 常數脫鉤
   - 修復：新增常數 `ErrHTTPHooksNotAvailable = "HTTP Hooks not available: requires Claude Code v%s+"` 於 version_detect_messages.go，使用 `fmt.Sprintf()` 動態組合
   - 位置：version_detect.go 第 179-184 行，version_detect_messages.go

3. **TC-25 重複測試刪除**
   - 問題：TC-25 `TestDetectClaudeVersion_DetectedVersionAccuracy` 與 TC-15 `TestDetectClaudeVersion_FullMode` 完全重複（都檢查 2.1.69 版本）
   - 修復：刪除 TC-25
   - 根據 linux 品味否決

#### 建議修復（評估後決定採納）

4. **CompareVersions 格式錯誤保守降級**
   - 問題：CompareVersions 在格式錯誤時返回 0（相等），導致解析失敗的版本被視為滿足最低版本（不保守）
   - 修復：改為返回 -1（版本過低），確保版本解析失敗時禁用 HTTP Hooks
   - 位置：version_detect.go 第 37-45 行

5. **Sentinel errors 註解補充**
   - 問題：sentinel errors 語義不清，需標明僅供測試用
   - 修復：添加註解說明測試用途，生產代碼應檢查 exec.CommandContext 回傳的實際錯誤類型
   - 位置：version_detect_constants.go

6. **JSON 編碼錯誤處理**
   - 問題：json.NewEncoder(w).Encode() 錯誤未被處理
   - 修復：檢查錯誤並記錄 warning log
   - 位置：version_detect.go 第 184-187 行
