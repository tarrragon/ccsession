除錯 Flutter WebSocket 連線失敗 — Backend health OK 但 app 顯示 Connecting

## Problem Analysis

### 問題根因

macOS App Sandbox entitlements 缺少 `com.apple.security.network.client` 權限。

- `DebugProfile.entitlements` 有 `network.server`（允許接收連線）但缺少 `network.client`（允許發起連線）
- `Release.entitlements` 兩者都缺少
- Flutter app 需要 `network.client` 才能連線到 `ws://localhost:8765/ws`
- Go Backend 完全正常（health check OK、WebSocket upgrade 101）

### 影響範圍

- `ui/macos/Runner/DebugProfile.entitlements` — 需新增 `com.apple.security.network.client`
- `ui/macos/Runner/Release.entitlements` — 需新增 `com.apple.security.network.client`

### 驗證方式

curl 測試 Backend WebSocket 回傳 101（成功），確認問題不在 Backend 端。
