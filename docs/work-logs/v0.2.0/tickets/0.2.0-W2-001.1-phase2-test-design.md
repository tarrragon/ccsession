## 1. 測試策略總覽

### 1.1 測試分層決策

依據 Hybrid Testing Strategy，本模組測試架構如下：

| 層級 | 名稱 | 測試範圍 | 框架 | 策略 |
|------|------|--------|------|------|
| **Unit** | 單元測試 | FileWatcher、SessionFileReader、JSONLParser 各自邏輯 | Go `testing` + `testify` | Table-Driven Tests |
| **Integration** | 整合測試 | FileWatcher + JSONLParser 端對端（tmpdir 模擬檔案系統） | Go `testing` | 黑盒文件系統 I/O |
| **Edge Cases** | 邊界測試 | 空檔案、不完整行、大量同時更新、競態條件 | Go `testing` | Scenario-Based |
| **Error Handling** | 容錯測試 | 各種錯誤情境（權限不足、檔案刪除、JSON 格式錯誤） | Go `testing` | Error Path Coverage |

### 1.2 Mock 策略（Sociable Unit Tests 原則）

| 依賴類型 | Mock 策略 | 理由 |
|---------|----------|------|
| fsnotify.Watcher | Mock | 外部依賴，無法在測試環境完全模擬 |
| os.File 讀寫 | 不 Mock | 使用 Go `os` 標準庫，直接在 tmpdir 測試 |
| time.Now() | 部分 Mock | 時間戳精度驗證時 Mock，其他使用真實時間 |
| JSON 解析結構 | 不 Mock | 驗證真實 JSONL 格式解析 |

### 1.3 測試檔案結構

```
server/
├── file_watcher.go              # 實作檔案（未來）
├── file_watcher_test.go         # FileWatcher 單元+整合測試
├── jsonl_parser.go              # 實作檔案（未來）
├── jsonl_parser_test.go         # JSONLParser 單元+邊界+容錯測試
├── testdata/                    # 測試資料目錄
│   ├── fixtures.go              # 測試 Fixture（JSONL 樣本）
│   ├── sample_user.jsonl        # 使用者訊息範例
│   ├── sample_assistant.jsonl   # Assistant 訊息範例（content array）
│   ├── sample_tool_use.jsonl    # Tool use 範例
│   ├── sample_malformed.jsonl   # 格式錯誤範例
│   └── sample_mixed.jsonl       # 混合類型範例
└── go.mod                       # 加入 fsnotify 依賴
```

## 2. 測試資料設計

### 2.1 JSONL 樣本資料

#### 樣本 1：使用者訊息

```json
{"type":"user","uuid":"msg-001","timestamp":"2026-03-25T10:00:00.000Z","sessionId":"session-abc","message":{"role":"user","content":"Hello, Claude"},"cwd":"/Users/test/project"}
```

**驗證點**：
- 解析為 1 個 SessionEvent
- Type = "user"，ContentIndex = -1
- Content.Text = "Hello, Claude"

#### 樣本 2：Assistant 訊息（Content Array）

```json
{"type":"assistant","uuid":"msg-002","timestamp":"2026-03-25T10:00:01.000Z","sessionId":"session-abc","message":{"role":"assistant","content":[{"type":"text","text":"Sure, I can help."},{"type":"tool_use","id":"tool-001","name":"web_search","input":{"query":"test"}},{"type":"text","text":"Let me search."}]},"cwd":"/Users/test/project"}
```

**驗證點**：
- 展開為 3 個 SessionEvent
- ContentIndex: 0, 1, 2
- IsLastContent: false, false, true
- 共享 MessageID = "msg-002"

#### 樣本 3：Tool Result

```json
{"type":"tool_result","uuid":"msg-003","timestamp":"2026-03-25T10:00:02.000Z","sessionId":"session-abc","message":{"role":"tool","content":{"tool_use_id":"tool-001","content":"Search results...","is_error":false}},"cwd":"/Users/test/project"}
```

**驗證點**：
- 解析為 1 個 SessionEvent
- Type = "tool_result"，ContentIndex = -1
- Content.Output = "Search results..."，IsError = false

#### 樣本 4：Thinking（嵌入 Assistant 內容）

```json
{"type":"assistant","uuid":"msg-004","timestamp":"2026-03-25T10:00:03.000Z","sessionId":"session-abc","message":{"role":"assistant","content":[{"type":"thinking","thinking":"Let me analyze..."},{"type":"text","text":"Analysis complete."}]},"cwd":"/Users/test/project"}
```

**驗證點**：
- 展開為 2 個 SessionEvent
- 第一個 Type = "assistant"，Content.Text 留空（thinking 無需設定 text）
- 第二個 IsLastContent = true

#### 樣本 5：不完整 JSON（無換行）

```json
{"type":"user","uuid":"msg-005","timestamp":"2026-03-25T10:00:04.000Z"
```

**驗證點**：
- 此行無結尾換行
- ReadNewLines 不處理此行
- offset 不更新

#### 樣本 6：格式錯誤的 JSON

```json
{"type":"user","uuid":"msg-006","timestamp":"2026-03-25T10:00:05.000Z","sessionId":"session-abc","message":{"role":"user","content":}
```

**驗證點**：
- JSON 無法解析
- ParseLine 回傳 nil, error
- 不發送 SessionEvent

#### 樣本 7：未知 Type（進度訊息）

```json
{"type":"progress","uuid":"msg-007","timestamp":"2026-03-25T10:00:06.000Z","sessionId":"session-abc","data":{"status":"pending"}}
```

**驗證點**：
- 被忽略（ParseLine 回傳 nil）

## 3. 單元測試案例：JSONLParser

### 3.1 ParseLine 系列測試

#### TC-P-001: 解析使用者訊息

```
名稱: TestParseLineUserMessage
Given: 一行有效的使用者 JSONL（message.content 為字串）
When:  呼叫 JSONLParser.ParseLine(line, filePath)
Then:  回傳 1 個 SessionEvent
       event[0].Type = "user"
       event[0].ContentIndex = -1
       event[0].IsLastContent = false
       event[0].Content.Text = "Hello, Claude"
       event[0].SessionID = "session-abc"
優先級: P0
```

**實作方式**（虛擬碼）：
```go
func TestParseLineUserMessage(t *testing.T) {
    parser := &JSONLParser{}
    line := `{"type":"user","uuid":"msg-001",...}`
    events, err := parser.ParseLine(line, "/Users/test/project/session-abc.jsonl")

    assert.NoError(t, err)
    assert.Len(t, events, 1)
    assert.Equal(t, "user", events[0].Type)
    assert.Equal(t, -1, events[0].ContentIndex)
    assert.Equal(t, "Hello, Claude", events[0].Content.Text)
}
```
