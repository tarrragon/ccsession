## 4. 虛擬碼

### 4.1 extractSearchableText(event)

```
FUNCTION extractSearchableText(event):
    results = empty list

    SWITCH event.type:
        CASE "user", "assistant":
            APPEND {field: "text", text: event.content.text} TO results

        CASE "thinking":
            IF event.content.text is NOT empty:
                APPEND {field: "text", text: event.content.text} TO results

        CASE "tool_use":
            APPEND {field: "toolName", text: event.content.toolName} TO results
            APPEND {field: "text", text: event.content.text} TO results

        CASE "tool_result":
            APPEND {field: "output", text: event.content.output} TO results
            APPEND {field: "text", text: event.content.text} TO results

        DEFAULT:
            // 回傳空列表

    RETURN results
```

### 4.2 findAllMatches(text, query)

```
FUNCTION findAllMatches(text, query):
    IF query is empty:
        RETURN empty list

    results = empty list
    lowerText = text.toLowercase()
    lowerQuery = query.toLowercase()
    searchFrom = 0

    LOOP:
        index = lowerText.indexOf(lowerQuery, startingFrom: searchFrom)
        IF index == NOT_FOUND:
            BREAK
        APPEND {start: index, end: index + length(query)} TO results
        searchFrom = index + length(query)   // 非重疊：從 end 開始

    RETURN results
```

### 4.3 ConversationSearchNotifier._performSearch()

```
FUNCTION _performSearch():
    IF query is empty:
        SET state to: matches=[], currentMatchIndex=-1
        RETURN

    events = READ from conversationNotifierProvider
    allMatches = empty list

    FOR EACH (eventIndex, event) IN events:
        searchableFields = extractSearchableText(event)
        FOR EACH {field, text} IN searchableFields:
            fieldMatches = findAllMatches(text, query)
            FOR EACH {start, end} IN fieldMatches:
                APPEND SearchMatch(
                    eventIndex: eventIndex,
                    startOffset: start,
                    endOffset: end,
                    field: field
                ) TO allMatches

    SET state to: matches=allMatches
    IF allMatches is NOT empty:
        SET currentMatchIndex = 0
    ELSE:
        SET currentMatchIndex = -1
```

### 4.4 updateQuery(query) + debounce

```
FUNCTION updateQuery(newQuery):
    SET state.query = newQuery
    CANCEL existing debounce timer (if any)
    START new timer(300ms):
        CALL _performSearch()
```

### 4.5 nextMatch / previousMatch

```
FUNCTION nextMatch():
    IF matches is empty: RETURN
    currentMatchIndex = (currentMatchIndex + 1) MOD matches.length

FUNCTION previousMatch():
    IF matches is empty: RETURN
    currentMatchIndex = (currentMatchIndex - 1 + matches.length) MOD matches.length
```

### 4.6 buildHighlightedSpans(text, ranges, baseStyle)

```
FUNCTION buildHighlightedSpans(text, ranges, baseStyle):
    IF ranges is empty:
        RETURN [TextSpan(text, baseStyle)]

    spans = empty list
    cursor = 0

    FOR EACH range IN ranges (sorted by start):
        IF cursor < range.start:
            APPEND TextSpan(text[cursor..range.start], baseStyle) TO spans
        highlightColor = IF range.isCurrent THEN orange(0.6) ELSE yellow(0.4)
        APPEND TextSpan(text[range.start..range.end], baseStyle + highlightColor background) TO spans
        cursor = range.end

    IF cursor < length(text):
        APPEND TextSpan(text[cursor..end], baseStyle) TO spans

    RETURN spans
```

### 4.7 events 變化時自動重新搜尋

```
IN ConversationSearchNotifier.build():
    conversationState = ref.watch(conversationNotifierProvider)

    IF conversationState.events is empty AND state.isSearchVisible:
        // session 切換：重置搜尋
        RETURN default state (isSearchVisible=false, query='', matches=[])

    IF state.isSearchVisible AND state.query is NOT empty:
        // events 變化：重新搜尋
        CALL _performSearch()
```

### 4.8 ConversationView 整合（高亮資料傳遞）

```
IN ConversationView build:
    searchState = ref.watch(conversationSearchNotifierProvider)

    // 為每個 event 計算 highlightRanges
    FOR EACH event at index IN events:
        matchesForEvent = searchState.matches
            .WHERE(match.eventIndex == index)
        highlightRanges = matchesForEvent.MAP(match =>
            {start: match.startOffset, end: match.endOffset,
             isCurrent: match == searchState.currentMatch})
        // 按 field 分組傳入 Bubble
```

## 5. 資料結構選擇

| 結構 | 選擇 | 理由 |
|------|------|------|
| SearchMatch | 不可變值物件 (Equatable) | 搜尋結果不需修改，支援相等比較 |
| ConversationSearchState | 不可變值物件 + copyWith | 與現有 ConversationState 模式一致 |
| matches 列表 | 有序列表 | 按 event 順序 + 欄位位置排序，支援索引導航 |
| HighlightRange | Record/Tuple | 輕量，只在 Widget 層短暫使用 |
| debounce timer | 單一可取消 timer | 每次輸入取消前一個，只需最新的 |

## 10. 權宜方案與技術債務

### 最小可行實作

- 搜尋為純同步遍歷，不做索引預建構
- debounce 使用簡單 Timer，不引入 RxDart
- 高亮只計算當前可見 + 全量（不做延遲計算最佳化）
- 捲動導航使用 ScrollController.animateTo 估算位置（非精確 GlobalKey）

### 已知限制

- 大量 events（>1000）時同步搜尋可能造成短暫 jank
- 捲動定位基於 eventIndex 估算，非精確像素定位
- 未實作搜尋歷史或正則模式

### 技術債務標記（Phase 4 建議）

| 項目 | 建議方向 |
|------|---------|
| 搜尋效能 | 考慮 Isolate 非同步搜尋或增量搜尋 |
| 捲動精度 | 使用 GlobalKey + ensureVisible 精確定位 |
| 延遲高亮 | 只計算可視區域 Bubble 的高亮（VisibilityDetector） |

## 11. 注意事項

### SessionEvent 欄位對應

Phase 1 spec 中 tool_use 搜尋 `content.toolName`，但 SessionEvent model 有兩個 toolName：
- `SessionEvent.toolName`（頂層）
- `EventContent.toolName`（content 內）

根據 Phase 1 spec 搜尋目標為 `content.toolName`，實作時以 `event.content.toolName` 為準。若兩者不一致需確認，但 extractSearchableText 應讀取 `event.content.toolName`。

### Bubble 向後相容

所有 Bubble 的 `highlightRanges` 參數必須為 optional（預設空列表），確保不傳入時行為不變（TC-SEARCH-67）。

### Riverpod codegen

ConversationSearchNotifier 使用 `@riverpod` 註解，需執行 `build_runner` 產生 `.g.dart`。
