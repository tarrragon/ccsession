## Problem Analysis

main.go 只註冊了 /health 和 placeholder hooks handler。核心元件（WebSocket Server、File Watcher、Session Registry、Event Dispatcher）完全未在 main.go 中初始化和連接。各元件獨立開發且通過單元測試，但從未整合。

另外 EventDispatcher.processSessionEvent 只呼叫 UpsertFromSessionEvent 更新 session 元資料，從未呼叫 AppendEvent 儲存事件到 history，導致 WebSocket get_session_history 始終返回空陣列。

## Solution

1. 重寫 server/main.go — 建立 channels 連接所有元件，啟動 goroutines，註冊 /ws endpoint
2. 新增 server/constants.go 的 main 層常數（buffer sizes, default port）
3. 新增 server/messages/log_messages.go 的 main 層 log 訊息
4. 修復 server/event_dispatcher.go — 在 processSessionEvent 中新增 AppendEvent 呼叫
