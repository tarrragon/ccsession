## Solution

### 實作概要

實作了版本檢測系統的核心功能模組：

1. **ParseClaudeVersion** - 從 claude --version 輸出中提取語義版本號
   - 使用正則表達式 `(\d+\.\d+\.\d+)` 匹配版本號
   - 支援多種格式：帶 v 前綴、帶後綴標籤（beta、stable）、多行輸出等
   - 異常情況安全降級，返回 ErrVersionParseFailure

2. **CompareVersions** - 三段版本比較（major.minor.patch）
   - 逐段整數比較，支援 <0=1 三態結果
   - 格式錯誤安全降級，返回 0（相等）

3. **常數定義** - version_detect_constants.go
   - 版本功能閾值：MinVersionHTTPHooks (2.1.63)、MinVersionFullFeatures (2.1.69)
   - CLI 常數：ClaudeCLICommand、ClaudeCLIVersionFlag、VersionPattern
   - VersionConfig 結構體：DetectedVersion、HTTPHooksEnabled、FullFeaturesAvailable
   - 5 個 Sentinel 錯誤：ErrVersionParseFailure、ErrVersionCmdFailed、ErrVersionCmdNotFound、ErrVersionCmdTimeout

### 設計決策

1. 使用指標 `*[3]int` 而非陣列表示版本分量，支援 nil 檢查表示解析失敗
2. CompareVersions 採用保守的安全降級策略：格式錯誤時返回 0（相等）而非拋出錯誤
3. parseVersionComponents 作為未導出函式處理核心邏輯，提供清晰的責任邊界
