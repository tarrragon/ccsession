## Problem Analysis

E2E 整合測試發現兩類前端錯誤：

錯誤 1：SessionEvent.fromJson 反序列化失敗
- 錯誤：type 'Null' is not a subtype of type 'String' in type cast
- 位置：session_event.g.dart:12 (_$SessionEventFromJson)
- 觸發：ConversationNotifier._handleSessionEvent 收到 session_event
- 原因：後端推送的 session_event JSON 中某個 String 欄位為 null，但 fromJson 做了非 nullable cast
- 需要：比對後端 Go struct 和前端 Dart model 的欄位定義，找出哪個欄位不一致

錯誤 2：SessionListNotifier 不認識 session_event/session_history 類型
- 日誌：SessionListNotifier: unknown message type: session_event / session_history
- 原因：SessionListNotifier._handleMessage 的 switch 沒有處理這些類型
- 影響：功能性影響不大（這些訊息本來就不是給 SessionList 的），但日誌噪音大
- 需要：在 switch default 中靜默忽略非相關類型，或只處理 session_list 類型
