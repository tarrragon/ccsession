## Solution

<!-- To be filled by executing agent -->

---

建立 deletion-residual-reference-hook.py，PostToolUse:Edit 觸發。

核心邏輯：
1. 從 stdin 讀取 tool_input（old_string, new_string, file_path）
2. 偵測刪除：old_string 比 new_string 長 >= 50 字元
3. 提取關鍵詞：Markdown 標題、數量詞、中文專有名詞、PascalCase 名詞
4. 過濾：排除 new_string 中仍存在的詞、排除被更長 term 包含的短 term
5. 搜尋殘留引用：在檔案當前內容中搜尋關鍵詞
6. 輸出 WARNING 到 stderr（不阻塞操作）

適用範圍：.md/.yaml/.yml/.json/.toml 檔案
註冊位置：settings.json PostToolUse:Edit
