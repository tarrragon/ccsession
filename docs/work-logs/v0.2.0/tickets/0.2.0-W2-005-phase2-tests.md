## 1. 測試策略

### 1.1 分層決策

| 層級 | 測試對象 | 測試類型 | 理由 |
|------|---------|---------|------|
| UseCase/Notifier | ConversationSearchNotifier | Unit (BDD) | Layer 3 業務邏輯，狀態管理核心 |
| UseCase/Helper | extractSearchableText, findAllMatches | Unit | 純函式，無副作用 |
| Widget | ConversationSearchBar | Widget | UI 互動驗證 |
| Widget | Message Bubble 高亮 | Widget | 渲染驗證 |

### 1.2 Mock 策略（Sociable Unit Tests）

| 依賴 | 策略 | 理由 |
|------|------|------|
| conversationNotifierProvider | Mock/Fake（提供固定 ConversationState） | 外部 Provider，隔離搜尋邏輯 |
| SessionEvent | 不 Mock，使用 test factory 建構真實物件 | Domain Entity |
| SearchMatch, ConversationSearchState | 不 Mock | Value Object |
| Timer (debounce) | 使用 fakeAsync | 控制時間 |

### 1.3 測試群組與拆分友善性

| 群組 ID | 功能職責 | 跨群組依賴 |
|---------|---------|-----------|
| TG-SEARCH-NOTIFIER | 搜尋狀態管理 + 匹配邏輯 + 導航 | 依賴 test factory |
| TG-SEARCH-HELPER | extractSearchableText / findAllMatches 純函式 | 依賴 test factory |
| TG-SEARCH-BAR | SearchBar Widget 渲染與互動 | 依賴 Fake Notifier |
| TG-SEARCH-HIGHLIGHT | Bubble 高亮渲染 | 無跨群組依賴 |

各群組可獨立執行，Phase 3b 可分派給不同代理人。

### 2.2 TG-SEARCH-NOTIFIER：ConversationSearchNotifier（Unit/BDD）

**測試環境設置**：
- 使用 ProviderContainer + override conversationNotifierProvider
- 提供包含已知文字的 events 列表
- debounce 相關測試使用 fakeAsync 控制時間

#### TC-SEARCH-20：openSearch — 開啟搜尋

- **優先級**：高
- **測試類型**：unit
- **Given**：Notifier 初始狀態（isSearchVisible=false）
- **Then（前置驗證）**：state.isSearchVisible == false
- **When**：呼叫 openSearch()
- **Then**：state.isSearchVisible == true, query == '', matches == [], currentMatchIndex == -1

#### TC-SEARCH-21：closeSearch — 關閉搜尋並重置

- **優先級**：高
- **測試類型**：unit
- **Given**：搜尋已開啟，有 query 和匹配結果
- **Then（前置驗證）**：state.isSearchVisible == true, state.matches.isNotEmpty
- **When**：呼叫 closeSearch()
- **Then**：state.isSearchVisible == false, query == '', matches == [], currentMatchIndex == -1

#### TC-SEARCH-22：updateQuery — 正常匹配（對應場景 2）

- **優先級**：高
- **測試類型**：unit
- **Given**：搜尋已開啟，events 包含 3 個 event：user("hello error"), assistant("no error here"), user("ok")
- **Then（前置驗證）**：state.isSearchVisible == true
- **When**：呼叫 updateQuery("error")，等待 debounce 300ms
- **Then**：state.matches.length == 2, currentMatchIndex == 0, matches[0].eventIndex == 0, matches[1].eventIndex == 1

#### TC-SEARCH-23：updateQuery — 大小寫不敏感（對應場景 3）

- **優先級**：高
- **測試類型**：unit
- **Given**：搜尋已開啟，events 包含 user("Error"), assistant("ERROR"), user("error")
- **When**：呼叫 updateQuery("error")，等待 debounce
- **Then**：state.matches.length == 3

#### TC-SEARCH-24：updateQuery — 無匹配（對應場景 8）

- **優先級**：高
- **測試類型**：unit
- **Given**：搜尋已開啟，events 包含 user("hello"), assistant("world")
- **When**：呼叫 updateQuery("xyz")，等待 debounce
- **Then**：state.matches.isEmpty, currentMatchIndex == -1, matchCountDisplay == "0/0"

#### TC-SEARCH-25：updateQuery — 空 query 清除結果（對應場景 9）

- **優先級**：高
- **測試類型**：unit
- **Given**：搜尋已開啟，已有匹配結果（query="error"）
- **Then（前置驗證）**：state.matches.isNotEmpty
- **When**：呼叫 updateQuery("")，等待 debounce
- **Then**：state.matches.isEmpty, matchCountDisplay == ''

#### TC-SEARCH-26：updateQuery — debounce 行為

- **優先級**：高
- **測試類型**：unit（fakeAsync）
- **Given**：搜尋已開啟
- **When**：快速連續呼叫 updateQuery("e"), updateQuery("er"), updateQuery("err")，間隔 < 300ms
- **Then**：只有最後一次 "err" 觸發搜尋（matches 基於 "err" 產生）

#### TC-SEARCH-27：updateQuery — 單一 event 多重匹配

- **優先級**：中
- **測試類型**：unit
- **Given**：搜尋已開啟，events 包含 user("error in error handling")
- **When**：呼叫 updateQuery("error")，等待 debounce
- **Then**：state.matches.length == 2, 兩個 match 的 eventIndex 都是 0, startOffset 分別為 0 和 9

#### TC-SEARCH-28：updateQuery — tool_use 搜尋 toolName（對應場景 11）

- **優先級**：高
- **測試類型**：unit
- **Given**：搜尋已開啟，events 包含 tool_use(toolName="Read", text="/file.dart")
- **When**：呼叫 updateQuery("Read")，等待 debounce
- **Then**：state.matches.length == 1, match.field == "toolName"

#### TC-SEARCH-29：updateQuery — tool_result 搜尋 output（對應場景 11）

- **優先級**：高
- **測試類型**：unit
- **Given**：搜尋已開啟，events 包含 tool_result(output="contents of main.dart")
- **When**：呼叫 updateQuery("main.dart")，等待 debounce
- **Then**：state.matches.length == 1, match.field == "output"

#### TC-SEARCH-30：nextMatch — 正常導航（對應場景 4）

- **優先級**：高
- **測試類型**：unit
- **Given**：搜尋已有 5 個匹配，currentMatchIndex == 0
- **Then（前置驗證）**：state.currentMatchIndex == 0, state.matches.length == 5
- **When**：呼叫 nextMatch()
- **Then**：state.currentMatchIndex == 1

#### TC-SEARCH-31：nextMatch — 循環到第一個（對應場景 4）

- **優先級**：高
- **測試類型**：unit
- **Given**：搜尋已有 5 個匹配，currentMatchIndex == 4（最後一個）
- **Then（前置驗證）**：state.currentMatchIndex == 4
- **When**：呼叫 nextMatch()
- **Then**：state.currentMatchIndex == 0

#### TC-SEARCH-32：previousMatch — 循環到最後（對應場景 5）

- **優先級**：高
- **測試類型**：unit
- **Given**：搜尋已有 3 個匹配，currentMatchIndex == 0
- **Then（前置驗證）**：state.currentMatchIndex == 0
- **When**：呼叫 previousMatch()
- **Then**：state.currentMatchIndex == 2

#### TC-SEARCH-33：previousMatch — 正常往回導航

- **優先級**：高
- **測試類型**：unit
- **Given**：搜尋已有 3 個匹配，currentMatchIndex == 2
- **When**：呼叫 previousMatch()
- **Then**：state.currentMatchIndex == 1

#### TC-SEARCH-34：nextMatch/previousMatch — 無匹配時無效

- **優先級**：中
- **測試類型**：unit
- **Given**：搜尋已開啟但無匹配（matches 為空）
- **Then（前置驗證）**：state.matches.isEmpty, state.currentMatchIndex == -1
- **When**：呼叫 nextMatch()
- **Then**：state.currentMatchIndex == -1（不變）
- **When**：呼叫 previousMatch()
- **Then**：state.currentMatchIndex == -1（不變）

#### TC-SEARCH-35：events 變化自動重新搜尋（對應場景 10）

- **優先級**：高
- **測試類型**：unit
- **Given**：搜尋 "test" 已有 2 個匹配（events 有 2 個含 "test" 的 event）
- **Then（前置驗證）**：state.matches.length == 2
- **When**：conversationNotifierProvider 的 events 新增一個含 "test" 的 assistant event
- **Then**：state.matches.length == 3（自動重新搜尋）

#### TC-SEARCH-36：session 切換重置搜尋（對應場景 12）

- **優先級**：高
- **測試類型**：unit
- **Given**：搜尋已開啟並有匹配結果
- **Then（前置驗證）**：state.isSearchVisible == true, state.matches.isNotEmpty
- **When**：conversationNotifierProvider 的 events 被清空（模擬切換 session）
- **Then**：state.isSearchVisible == false, state.query == '', state.matches == []

#### TC-SEARCH-37：matchCountDisplay 衍生屬性

- **優先級**：中
- **測試類型**：unit
- **Given/When/Then**（三組）：
  1. query="" -> matchCountDisplay == ""
  2. query="xyz", matches=[] -> matchCountDisplay == "0/0"
  3. query="error", matches.length=5, currentMatchIndex=2 -> matchCountDisplay == "3/5"

#### TC-SEARCH-38：currentMatch 衍生屬性

- **優先級**：低
- **測試類型**：unit
- **Given/When/Then**（兩組）：
  1. currentMatchIndex == -1 -> currentMatch == null
  2. currentMatchIndex == 0, matches.length == 3 -> currentMatch == matches[0]

#### TC-SEARCH-39：updateQuery — 1 字元搜尋

- **優先級**：中
- **測試類型**：unit
- **Given**：搜尋已開啟，events 包含 user("a"), assistant("b"), user("a")
- **When**：呼叫 updateQuery("a")，等待 debounce
- **Then**：state.matches.length == 2
