## 1. 實作策略設計

### 核心修改

在 `scan_pending_handoff_tasks()` 的「Ticket 未完成」分支中，插入 direction 前綴判斷。auto 類型直接歸入 recent_tasks，跳過 `is_ticket_recently_started()` 判斷。

### 虛擬碼

```
FUNCTION scan_pending_handoff_tasks(project_root, logger):
    FOR each JSON file in pending directory:
        IF resumed_at is not null:
            SKIP (already resumed)

        IF ticket is completed:
            IF should_preserve(direction):
                ADD to pending_tasks
            ELSE:
                DELETE file (GC)
        ELSE:
            // --- 新增邏輯開始 ---
            direction_type = direction.split(":")[0]
            IF direction_type == "auto":
                ADD to recent_tasks
                LOG INFO "auto handoff 為建議性任務，不阻塞退出"
            // --- 新增邏輯結束 ---
            ELIF is_recently_started(ticket_id):
                ADD to recent_tasks
            ELSE:
                ADD to pending_tasks

    RETURN (pending_tasks, recent_tasks)
```
