# v0.2.0 工作日誌

## 版本目標

Go Backend 核心監控能力：後端服務可獨立運作，透過 JSONL file watching 和 HTTP Hooks 雙源架構監控本地 session，並以 WebSocket 對外推送即時事件。

本版本不包含 Flutter UI（後續 v0.2.1 處理）。

## 版本里程碑

`go run ./server` 啟動後：
- 自動偵測 `~/.claude/projects/` 下的 JSONL 檔案並開始監控
- 接收 Claude Code HTTP Hooks 事件（SubagentStart/Stop/TaskCompleted）
- 透過 WebSocket (`ws://localhost:8765/ws`) 推送即時 session 事件
- 可用 `wscat -c ws://localhost:8765/ws` 或 `curl` 驗證全流程

> 詳細架構設計見：`docs/work-logs/v0.2.0/tickets/0.2.0-W2-001-sa-architecture-review.md`
