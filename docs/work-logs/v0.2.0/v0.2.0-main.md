# v0.2.0 工作日誌

## 版本目標

Claude Code Multi-Agent Session Monitor MVP：Go Backend + Flutter Frontend 完整即時監控系統。後端透過 JSONL file watching 和 HTTP Hooks 雙源架構監控本地 session，以 WebSocket 對外推送即時事件；前端提供 Session List、Conversation View、Split View、搜尋篩選等完整 UI。

## 版本里程碑

`go run ./server` 啟動後：
- 自動偵測 `~/.claude/projects/` 下的 JSONL 檔案並開始監控
- 接收 Claude Code HTTP Hooks 事件（SubagentStart/Stop/TaskCompleted）
- 透過 WebSocket (`ws://localhost:8765/ws`) 推送即時 session 事件
- 可用 `wscat -c ws://localhost:8765/ws` 或 `curl` 驗證全流程

## 架構決策

> 詳細架構設計見：`docs/work-logs/v0.2.0/tickets/0.2.0-W2-001-sa-architecture-review.md`

核心決策：
1. HTTP Hooks 為主（系統狀態變化）+ JSONL watching 為備（完整對話內容）
2. 雙源事件在 Event Dispatcher 融合，統一推送至 WebSocket
3. HTTP Hooks 依賴 Claude Code v2.1.63+；版本降級策略延後至 v0.2.2 實作

## 主要成果

### Go Backend (server/)

- JSONL file watching + HTTP Hooks 雙源事件架構
- Session Registry 狀態機（active/idle/completed）
- Event Dispatcher 事件融合與去重
- WebSocket Server 即時推送（session_list/session_event/session_history/session_status_change）
- HTTP Hooks 版本偵測與 fallback 降級機制

- WebSocket Client（自動重連、指數退避策略）
